# 标准分析流程

## 一、分析前置

### 1.1 数据新鲜度判断

检查 `macro_memo.md` 的 `updated` 字段：

| 时间差 | 复用规则 |
|--------|---------|
| < 10 分钟 | 直接复用上次结论 |
| 10~60 分钟 | 复用但补充说明，仅刷新关键因子（机会成本/货币/避险） |
| > 60 分钟 | 全部重跑 |
| 跨日期（隔夜） | 全部重跑 + 检查隔夜事件 |

标注输出顶部：`✅ 实时` / `⚠️ 部分数据截至 {时间}` / `❌ 数据过期`

### 1.2 推理标注规则 ⚠️ 严格遵守

> **核心原则**: 没有数据支撑的判断，必须明确标注推理等级。
> 
> ⚠️ **禁止用价格反推原因**: "因为跌了1.71% → 所以数据不好" 是循环论证。
> 价格涨跌受多因素共同作用，与单一事件之间没有严格的因果一一对应关系。
> 利好事件也可能跌(买预期卖事实)，利空事件也可能涨(利空出尽)。

所有非直接从数据读取的结论必须严格标注：

| 标注 | 含义 | 允许条件 | 示例 |
|:----:|:----|:---------|:-----|
| `(数据)` | 直接从工具返回读取 | 工具输出中有明确值 | "CPI实际为4.5% `(数据)`" |
| `(推断)` | 基于已有数据的合理推断 | 有具体数据支撑+逻辑链条 | "TIPS 8bp跳升 → 加息预期强化 `(推断:TIPS+8bp)`" |
| `(经验)` | 基于交易经验 | 必须说明经验来源 | "历史数据窗口波动通常放大 `(经验)`" |
| `(搜索)` | 从 WebSearch 获取 | 需保留搜索来源 | "中东局势升级 `(搜索: reuters)`" |
| `(猜测)` 🚫 | 无数据支撑的推测 | **禁止使用** | 出现即视为分析错误 |

**标注格式规则**:
- `(推断)` 后跟冒号+关键证据，如 `(推断: TIPS↑8bp, DXY 120)`
- 标注不足的分析结论，在输出末尾追加 `(标注缺失)` 警示

**典型错误场景 — 禁止**:
- ❌ 价格跌了 → 数据一定不好 (价格由多因素共同决定)
- ❌ 数据符合预期 → 涨跌应该按我预测的方向 (市场定价已经提前消化)
- ❌ 因子看多 → 一定涨 (因子有滞后性，技术面可能有冲突)

### 1.3 上下文加载

加载: user_profile.md, positions.md, macro_memo.md, 1_宏观三维七因子归因框架.md

### 1.4 数据就绪检查

```bash
python data_query.py snapshot
python data_query.py factors
python data_query.py macro
```

### 1.5 预判验证与权重调整

```bash
python tools/verify_predictions.py
```

| 场景 | 处理 |
|------|------|
| 首次分析 | 跳过验证，使用默认权重 |
| 有未验证预判, >60min | 执行完整验证 |
| 有未验证预判, <10min | 跳过验证 |
| 某因子准确率 < 40% | 下调该因子权重，输出提示 |

## 二、核心分析流程（六步）

```
Step 1: 宏观体检     → 快速扫描，了解当前状态
Step 2: 因子深度分析  → 七因子逐个读 + 查知识库
Step 3: 技术面验证    → 价格行为是否支持因子信号
Step 4: 场景分类      → 判断主导周期 + 市场regime
Step 5: 信息增量      → 事件/新闻/搜索补充
Step 6: 场景推演      → 2-3条情景路径 + 综合输出
```

---

### Step 1: 宏观体检

```bash
python data_query.py snapshot
python data_query.py macro
```

关注清单: 金银价格(涨跌/幅度)、TIPS 10Y(绝对值/日变化)、DXY(绝对值/日变化)、VIX(绝对值/日变化)、美债10Y(日变化)

输出一句话概括当前状态。与 macro_memo 上次判断对比价格变化/因子变化/事件变化。

**交易时段检查**（可选）：当前时间落在哪个交易时段？若处于三盘叠加或数据窗口，在输出中标注"当前处于{时段}，波动可能放大"。

变化不大 → 沿用上次判断。有重大变化 → 继续后续步骤。

---

### Step 2: 因子深度分析

```bash
python data_query.py factors
python data_query.py factors opportunity_cost  # 单因子
```

**每个因子分析要点**:

| 因子 | 核心问题 | 重点关注 |
|------|---------|---------|
| 机会成本 | TIPS 趋势？降息预期？ | TIPS 20日趋势、FedWatch概率 |
| 货币 | DXY 趋势？正交贡献？ | DXY vs 200MA |
| 避险 | VIX 水平？信用利差？ | VIX 趋势、是否流动性危机 |
| 通胀预期 | 盈亏平衡趋势？CPI momentum？ | Breakeven 趋势、原油 |
| 持仓动量 | OI 变化？COT 拥挤度？ | OI+价格组合信号、COT分位 |
| 结构性需求 | 央行购金趋势？ | 去美元化叙事 |
| 银价专用 | 金银比位置？工业需求？ | 金银比分位、库存趋势 |

输出: 每个因子的方向 + 强度 + 关键证据。

---

### Step 3: 技术面验证

```bash
python data_query.py technical                    # 全部品种
python data_query.py history gold 30              # 趋势/形态
python data_query.py history silver 30
```

检查清单: 趋势方向(MA20/MA60/MA200)、动量状态(高低点排列)、超买超卖(>2σ)、关键价位(30日高/低)、背离检查(价格与动量是否一致)

**双层信号对照**:

| 因子 | 技术面 | 综合 |
|------|--------|------|
| ↑ | 趋势向上，无超买 | 确认看多 |
| ↑ | 趋势向上，超买/近阻力 | 看多，等回调 |
| ↑ | 趋势向下/震荡 | 暂缓 |
| ↓ | 趋势向下，无超卖 | 确认看空 |
| ↓ | 趋势向下，超卖/近支撑 | 看空，等反弹 |
| ↓ | 趋势向上/震荡 | 暂缓 |
| 中性 | 趋势明确 | 轻仓顺技术面 |

---

### Step 4: 场景分类

```bash
python data_query.py factors  # 检查 short/mid/long 信号
```

判断流程:
```
4a: 短期异常？
  ├─ 短期信号 > 0.7？
  │   ├─ 有事件 → 情绪/事件驱动
  │   └─ 无事件 → 趋势加速/衰竭
  └─ 否 → 4b
4b: 中期+长期同向且一致(差异<0.2)？
  ├─ 是 → 趋势驱动
  └─ 否 → 4c
4c: 短期与中长期相反？
  ├─ 短期情绪性 → 趋势中的回调
  └─ 短期基本面 → 可能转折
4d: 信号混乱无主导因子 → 震荡/噪音
```

五种场景:
| 场景 | 策略 |
|------|------|
| 趋势驱动 | 顺势，持仓/加仓 |
| 情绪/事件驱动 | 等情绪消退，观望或小仓位短线 |
| 震荡/噪音 | 观望 |
| 趋势中回调 | 回调企稳后加仓 |
| 可能转折 | 减仓/对冲 |

---

### Step 5: 信息增量

```bash
python data_query.py events
python data_query.py news_by_factor <主导因子ID>
WebSearch  # 知识库不足以解读时
```

优先用 `data_query`，知识库能回答的不搜网页，WebSearch 结果交叉验证。

---

### Step 6: 场景推演 & 综合输出

情景 A（基准）：事件符合预期 → 延续趋势
情景 B（偏多）：事件超预期偏多 → 加速/反转
情景 C（偏空）：事件超预期偏空 → 加速/反转

每条情景包含: 概率、影响(方向+幅度)、持仓影响、切换条件。

## 四、特殊场景

| 情况 | 处理 |
|------|------|
| 因子数据不全 | 标注"数据缺失"，降低权重 |
| 全部数据缺失 | 告知用户管道异常，不做分析 |
| 行情无变化 | 沿用上次判断 |
| 因子间矛盾 | 找主导因子，弱势因子降权 |
| 因子与技术面矛盾 | 以因子为主，技术面提示时机风险 |
| 判断与市场走势矛盾 | 优先市场走势，检讨错误 |

### 判断错误处理

诚实承认 → 分析错在哪(因子/解读/变量/冲击) → 修正 → 记录 decisions.md

**常见错误类型**：

| 错误类型 | 说明 | 防范 |
|:--------|:-----|:-----|
| 用价格反推原因 | 看到跌了就说数据不好（循环论证） | 严格1.2标注规则，标注 `(猜测)` 即视为错误 |
| 单一归因 | 忽略多因素共同作用 | 每次分析必须跑所有可用因子 |
| 忽略滞后性 | 市场已在数据发布前消化预期 | 异动分析时检查数据窗口前后价格行为 |
| 标注缺失 | 结论缺乏必要的数据标注 | 输出末尾追加 `(标注缺失)` 警示 |

# 短线异动归因流程

> 日内波动 > 1%(黄金)或 > 2%(白银)、或用户要求归因时执行。

与标准分析区别: 极速归因30秒出结论、跳过技术面验证和情景推演、不查知识库。

## 归因流程（六步）

```
Step 1: 确认异动参数（5秒）
  ├─ 品种？跌/涨多少？从几点开始？
  ├─ 还在动还是稳住了？
  └─ data_query.py snapshot + history <品种> 5
      ↓
Step 2: 事件排查（10秒）← 第一优先级
  ├─ data_query.py events → 日历
  ├─ data_query.py news   → 突发
  └─ WebSearch（必要）
    → 先输出结论: 有事件/无事件
    → 然后执行 交易时段判断（见下方 Step 2b）
        ↓

### Step 2b: 交易时段判断

在事件排查后立即执行。判断异动时间点是否落在关键交易窗口。

**判断逻辑**：
1. 确定异动发生时间（北京时间 CST）
2. 对照关键时段表检查
3. 仅当命中关键窗口时输出，否则跳过

**关键交易时段参考表（北京时间 CST）**：

| 时段 | 时间(CST) | 市场状态 | 对异动影响 |
|------|-----------|---------|-----------|
| 亚盘 | 09:00-15:00 | SHFE日盘，流动性偏低 | 异动多为隔夜情绪延续或事件驱动 |
| 欧盘 | 15:00-23:30 | 伦敦时段，流动性中等 | 欧央行/英央行事件窗口 |
| 美盘 | 21:30-05:00 | 纽约时段，流动性高 | 美国数据/讲话窗口 |
| **三盘叠加** | **21:00-23:00** | **SHFE夜盘+伦敦+纽约** | **流动性峰值，踩踏传导最快** |
| 美欧叠加 | 15:00-23:30 | 伦敦+纽约重叠 | 成交放大，趋势加速 |
| **美国数据窗口** | **20:30-22:00** | 经济数据密集发布 | 脉冲式异动高发期 |
| FOMC窗口 | 02:00-03:00 | 利率决议/纪要 | 方向性突破高发 |
| COMEX结算 | 02:28-02:30 | 结算价确定 | 异动可能失真 |
| SHFE收盘 | 14:50-15:00/23:50-00:00 | 日/夜盘收盘 | 平仓压力 |

**输出规则**：
- 命中三盘叠加或美国数据窗口 → 输出 [交易时段]，标注"关键窗口放大波动"
- 命中其他窗口 → 输出简版标注
- 未命中关键窗口 → 不输出

        ↓
Step 3: 因子快速排查（15秒）
  第一层: TIPS急变→机会成本 / DXY急变(且TIPS没动)→货币 / VIX跳升→避险
  第二层: 金银同向→支持宏观 / 金跌银不跌→白银工业对冲 / 金银比急变→白银独立
  第三层: OI骤降→踩踏 / OI骤增→新开仓
  第四层: 关键位突破触发止损 / 交割日效应
  → data_query.py snapshot + macro + factors
      ↓
Step 4: 预期评估（10秒）
  类型: 数据发布/讲话→脉冲式 / 地缘→持续性 / 宏观转向→持续性
  区间: 基于近30日ATR (±1σ正常 / ±2σ极端)
  → data_query.py history <品种> 30
      ↓
Step 5: 持仓影响（5秒）
  品种？方向？距成本/止损多远？需立即行动？
  → positions.md
      ↓
Step 6: 输出
```

## 输出格式

```
⚡ 异动归因 | HH:mm | 数据截至: YYYY-MM-DD HH:mm

[品种] [方向] [幅度] | 当前价 [价格]

── 事件 ──
[有/无] 明确事件触发: {详情}

── 交易时段 ── (仅当命中关键窗口时输出)
{时段名} {时间} | {市场状态} | 影响: {对异动速度/幅度的解释}

── 因子变动 ──
TIPS: 当前值 | 日内变化 | 影响
DXY:  当前值 | 日内变化 | 影响
VIX:  当前值 | 日内变化 | 影响
金银比: 当前值 | 日内变化
→ 主导归因: {因子名}

── 预期评估 ──
类型: {脉冲式/持续性} | 预计: {时长} | 区间: {支撑-阻力} (ATR: XX)

── 持仓影响 ──
{品种} {方向}: 距成本 +/-XXX | 止损 XXX | 建议: {持有/减仓/止损/观望}

建议: {一句话}
```

## 升级条件

有事件触发 + 因子变动 > 1σ → 升级为标准分析 Step 4-6 → 更新 macro_memo
无事件 + 因子变动 < 1σ → 短期波动，不升级

## 极端行情

触发: 日内 > 2%(黄金) 或 > 4%(白银)
处理: 执行异动归因 → 有持仓立即预警 → 判断流动性危机(VIX>35+信用利差飙升+DXY走强) → 流动性危机建议减仓不抄底
