# 期权波动率事件扫描（期权机会发现）v2

> v1 仅覆盖沪金/沪银、用绝对 IV<25% 单阈值、无定价检验、无全系列扫描、无止损建模。
> v2 针对实盘/全扫发现的 11 个问题全部重构（见文末「待迭代→已实现」）。
> 设计起因：2026-08-05 沪金2610C1000 单日+101%（标的2日+6.4%穿越虚值），镇哥要求系统化覆盖此类机会并固化成 skill。

## 触发逻辑（四层叠加 L1→L4）

| 层 | 信号 | 阈值（v2） |
|:--|:--|:--|
| L1 方向 | 标的异动 + 趋势 | 5日涨幅 > 2% 或 破20日高；且 close > MA20 且（MA20上行 或 破20日高） |
| L2 事件窗 | 临近宏观事件 | 未来 3-10 天有 NFP 或 FOMC（仅 AU/AG 走事件链；工业品种走纯波动率链，不依赖事件） |
| L3 便宜（双口径） | IV 真低 | **IV/HV20 < 1**（真便宜）**且 IV ≤ 24% 且 IV 近1年历史分位 < 30%** |
| L4 定价合理性 | 买方没在给不兑现的波动付费 | `event_pricing_check`：IV隐含单日波动 vs 该事件历史实际单日波动（如非农沪金次日 |涨跌| 分布）→ CHEAP / FAIR / EXPENSIVE |

- **L4 裁决**：隐含单日波动 ÷ 历史实际中位 ≥ 1.0 → CHEAP（真机会）；≥ 0.75 → FAIR；< 0.75 → EXPENSIVE（负期望，不买）。
  - 实测 AU IV 25.8% 隐含单日 1.63%，非农历史实际中位仅 0.78%（n=35，仅 11% 超过该比值）→ **EXPENSIVE**，印证裸买在贵 IV 下是送钱。
- **工业品种路径**（CU/AL/ZN/RB/SC）：无宏观事件依赖，L1→L3 直接触发（纯低波动率高盈亏比），避免 v1 把非宏观品种 L4 硬编码 False 导致永不触发。

触发后选品：
- 流动性 TOP 的轻度虚值 Call（虚值 1%-5%）；权利金=结算价；BE = 行权价 + 权利金；最大亏损 = 权利金（封顶）；仓位 ≤ 权益 1-3%（探针仓）。
- **IV/HV > 1（IV 贵）时自动切牛市价差（bull call spread）**：买轻度虚值 Call + 卖更高行权 Call，近乎 vega 中性，避免把权利金送给 vega。代价：盈利封顶。
  - 实测 au2612 买C960卖C1000（成本 13,100/手），IV 从 26%→19% 崩落时，标的 +1%/+2%/+3% 收益仍 +4%/+14%/+24%；同场景裸买 au2610C1000 在标的 +1% 时亏 32%。

## 用法
```bash
# 实时扫描（全品种横扫，输出候选合约 + 入场/止损/仓位 + L1-L4 裁决）
python option_event_scan_v2.py scan                 # 全品种
python option_event_scan_v2.py scan AU AG           # 指定品种

# 预热 IV 历史（首跑/定期刷新分位缓存）
python option_event_scan_v2.py warm                 # 全品种
python option_event_scan_v2.py warm CU AL ZN RB SC

# 单事件定价合理性检验（L4）
python option_event_scan_v2.py pricing AU NFP
python option_event_scan_v2.py pricing AU FOMC

# 历史回测（默认 AU，窗口 2025-01 ~ 2026-08）
python option_event_scan_v2.py backtest AU 20250101 20260806            # 全事件 / strict 趋势
python option_event_scan_v2.py backtest AU 20250101 20260806 --nfp-only # 仅 NFP（强过滤）
python option_event_scan_v2.py backtest AU 20250101 20260806 --ivhv       # 额外用 IV/HV 口径回测
python option_event_scan_v2.py backtest AU 20250101 20260806 --flex      # 柔性趋势（抓底部反转起爆点）
# 趋势口径默认 strict（更干净、回测更优）；--flex 放开"破20日高"替代 MA20上行
```

## 回测结论（2025-01 ~ 2026-08，沪金 AU，关键发现）

**v2 strict（默认，23 次触发 / 23 入场日）**
- H=10 全事件：胜率 60.9%，均值 +140.5%，探针仓 2% → 账户 **+85.2%**
- H=10 **仅 NFP**：胜率 86.7%，均值 +239.9%，账户 **+99.4%**（过滤后明显更优）
- H=20 全事件：账户 +65.0%；NFP-only 账户 +79.7%、胜率 100%

**🔑 真·alpha = NFP 过滤，不是止损**
- NFP 前买 Call ≈ 86-100% 胜率；FOMC 前盲买 Call 胜率仅 ~17%、均值 -41% → 宏观研判是命门，FOMC 必须叠鸽/鹰派过滤（v2 用 `--nfp-only` 实现）。
- v1 全事件账户 +115% 略高于 v2 全事件 +85.2%，但 v2 NFP-only +99.4% 与之相当且更干净——v2 收紧 IV≤24% / min_days≥3 后改变了部分入场点，属预期内。

**止损建模（-50% 硬止损，逐日路径检测）**
- 止损是**风险封顶**（-50%），不是收益增强器：H=20 全事件账户 +65.0% → +46.0%（砍掉赢家路径波动）；H=10 NFP 几乎无影响（+99.4% vs +99.4%）。
- 结论：探针仓本就封顶亏损=权利金，止损主要防"标的反向+时间损耗"的归零路径，建议开启但不指望它提收益。

**趋势口径：strict 默认，flex 仅手动**
- flex 在本样本仅多触发 2 笔（均为 FOMC 输家），未捕获额外 NFP 赢家 → strict 更优。
- flex 价值在"底部反转起爆点"（MA20 仍下行但破20日高），其他 regime 可能有用，故保留 `--flex` 供手动抓反转，不设为默认。

## 沪银 AG 与工业品种（不适用裸买，已弃用裸买路径）
- AG 探针仓仅 +3.6%（打平偏亏）：白银 IV 天然高、低 IV 窗口稀缺、事件前异动多脉冲假突破、对货币驱动响应不如黄金纯粹 → v2 不再把 AG 当主战场，仅作扫描输出参考。
- 工业品种（CU/AL/ZN/RB/SC）走纯波动率链（L1→L3，无事件依赖），双 IV 口径下当前样本均"不便宜"（实测 8/6 全 7 品种 IV/HV：SC 0.93 / RB 1.24 / AL 1.25 / AG 1.26 / ZN 1.37 / AU 1.43 / CU 1.96），故实盘常扫不到机会，符合"贵就不买"的设计。

## 已知限制 / 后续
- 回测窗口为 2025-26 牛市样本（含趋势 beta），需补 2019-2024 震荡/熊市验证 alpha。
- L4 事件历史波动分布目前硬编码 NFP/FOMC 的沪金样本（n=35），其他品种/事件需补样本。
- 接入守护任务自动扫描：`scan` 已可跑，需接每日自动化 + 看板/飞书推送"期权机会提示"。
- **v2.1 架构改进（镇哥 8/7 定）**：事件不应是唯一入口，而是因子之一。当前 L2 把"NFP 剩 1 天"当硬否决 → 观感=无事件不扫。改法：① 事件层降级为加权因子（有事件叠事件溢价判断，无事件走纯走势/IV/情绪链，如工业品种 L1→L3 已示范）；② 新增"期权动量追踪"维度（权利金连续放量+突破 N 日高 → 追势提示器，与埋伏哲学相反、高风险轻仓）；③ 每日扫描改为"当前走势/数据指标/情绪面 + 未来 1-2 周事件日历"综合输入，而非单一事件触发。
