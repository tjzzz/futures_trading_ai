## 设计思路

整体分析框架 = **因子归因分析 + 技术面分析**，两者并列互补：

- **因子归因分析** — 回答"金价为什么涨/跌"，基于因果机制驱动，用于归因和方向判断
- **技术面分析** — 回答"在哪个点位进出"，基于价格形态和指标信号，用于入场/出场时机和仓位管理

因子归因定方向，技术面定时机。两者解决的是不同层面的问题，缺一不可。

### 因子定价模型

金价是零息资产，因子层面的定价逻辑：

```
金价 = f(机会成本, 货币, 避险, 通胀预期, 持仓动量, 结构性需求) + 事件冲击
```

### 三原则

1. **因果机制优先** — 先定义"为什么X变化导致金价变"，再挂指标
2. **同一因子跨时间尺度** — 短期看变化量，中期看趋势，长期看regime
3. **因子正交化** — DXY与TIPS高度相关（~0.5-0.6），需剥离重叠部分

## 技术面分析层

**定位**：技术面不独立判断方向，而是验证因子信号 + 提供交易时机。宏观因子定方向，技术面定时机。

### 与技术面的关系

```
因子归因 → 判断方向（看多/看空/中性）
     ↓
技术面   → 验证信号（因子看多，价格行为是否支持？）
          → 定位时机（关键支撑/阻力在哪？当前是否超买/超卖？）
          → 风险评估（趋势强度如何？波动率多大？）
```

### 技术指标分类

#### 趋势类

| 指标 | 用途 | 与因子层联动 |
|------|------|-------------|
| MA20/60/200 排列 | 判断中短期趋势方向 | 因子看多 + MA多头排列 → 信号确认 |
| 趋势线/通道 | 识别趋势延续或破位 | 因子信号转变 + 趋势线破位 → 可能转折 |
| ADX(14) | 衡量趋势强度 | ADX < 20 → 震荡市，因子信号可靠性降低 |

#### 动量类

| 指标 | 用途 | 与因子层联动 |
|------|------|-------------|
| RSI(14) | 超买(>70)/超卖(<30) | 因子看多 + RSI > 70 → 短期回调风险 |
| MACD | 金叉/死叉、柱线背离 | 因子看多 + MACD顶背离 → 信号冲突，需警惕 |

**背离信号处理规则**：
- 价格新高但 RSI/MACD 未新高 → 顶背离 → 因子看多信号需打折
- 价格新低但 RSI/MACD 未新低 → 底背离 → 因子看空信号需打折
- 背离出现 + 因子信号转变 → 有效转折信号

#### 支撑阻力

| 指标 | 用途 | 与因子层联动 |
|------|------|-------------|
| 前高前低 | 关键价位识别 | 因子看多 + 价格接近前高 → 突破确认或遇阻 |
| 斐波那契回撤 | 回调目标位 | 回调至 0.382/0.5/0.618 → 观察是否获得支撑 |
| 成交量密集区 | 筹码分布 | 放量突破关键位 → 信号可靠 |

#### 波动率

| 指标 | 用途 | 与因子层联动 |
|------|------|-------------|
| ATR(14) | 波动率测量 | 高波动期(ATR扩张) → 降低仓位，放宽止损 |
| 布林带 | 超买超卖+波动率 | 布林带收窄 → 突破在即；突破布林带上轨 → 趋势强劲 |

### 技术面的双层过滤规则

```
因子信号 → 强信号（强度>0.6）
               → 技术面验证（趋势+动量+位置）
                     → 三者一致 → 高确信度执行
                     → 趋势支持但动量超买 → 等回调
                     → 趋势不支持 → 暂缓

因子信号 → 弱信号（强度<0.4）
               → 不操作，仅监控

因子信号 → 中性/混乱
               → 技术面找方向（震荡偏多或偏空）
               → 但严格控制仓位
```

## 因子1：机会成本

黄金是零息资产，持有黄金的机会成本就是实际利率。这是金价最强的单一驱动因子，实证相关系数约 -0.85 ~ -0.90。

| 时间尺度  | 核心指标                        | 量化方式                                                 |
| ----- | --------------------------- | ---------------------------------------------------- |
| **短** | ΔTIPS(日)、Δ10Y名义收益率          | ΔGold ≈ -β₁ · ΔTIPS，β₁ ≈ 15-20x（TIPS变动1bp，金价反向约$2-4） |
| **中** | TIPS 20日/60日趋势、FedWatch利率概率 | TIPS处于历史低位区间 → 金价有中期支撑；FedWatch降息概率↑ → 金价中期偏强        |
| **长** | 实际利率regime方向                | 下降regime → 金价牛市；上升regime → 金价熊市                      |

---

## 因子2：货币

金以美元定价，美元↑ → 对非美买家黄金变贵 → 需求↓。但DXY与TIPS相关系数约0.5-0.6（Fed加息 → 利率↑ + 美元↑），所以DXY对金价的解释力中约一半已被因子1捕获。**货币因子的独立贡献需要正交化——扣除与TIPS同步变动的部分。**

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | ΔDXY_ortho(5min) — 扣除与TIPS同步变动的正交部分 | ΔGold_货币 ≈ -β₂ · ΔDXY_ortho |
| **中** | DXY 60日趋势、DXY vs 200日均线位置 | DXY持续低于200MA → 金价中期偏强 |
| **长** | 美元在全球外储中占比趋势（IMF COFER） | 美元储备占比持续下降 → 金价长期中枢上移 |

**与机会成本因子的归因原则**：
- 先归因因子1（实际利率变动），再归因DXY中与因子1正交的独立部分
- 美元走弱但利率不变 → 货币因子独立贡献显现
- 两者同向 → 只算一次，避免重复

## 因子3：避险需求

**非单调因子**：中度恐慌利好黄金，极端恐慌（流动性危机）利空黄金。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | VIX日变化、S&P500日跌幅、信用利差(HYG-LQD)变化 | VIX > 30 且未出现流动性冻结 → 金价短期走强 |
| **中** | VIX 20日均值、MOVE指数（美债波动率）、信用利差趋势 | VIX持续高于20 → 金价有中期避险溢价 |
| **长** | 地缘风险中枢、大国冲突频率、制裁数量/贸易碎片化 | 多极化加速 → 金价长期风险溢价中枢上移 |

**流动性危机 vs 避险的区分**：

| 场景 | VIX | 信用利差 | TED Spread | 美元 | 黄金 |
|------|-----|---------|-----------|------|------|
| 正常避险 | ↑ | 略扩 | 平稳 | 略弱 | **↑** |
| 流动性危机 | ↑↑ | ↑↑↑ | ↑↑ | ↑（抢美元） | **↓**（抛售变现） |

判断关键：**信用利差是否同时飙升 + TED Spread是否走阔**

## 因子4：通胀预期

与机会成本因子有重叠但不等同。关键区分场景：**滞胀**——名义利率和通胀同时上升，实际利率可能不变，但"通胀对冲"叙事本身驱动买入。2022年就是这个模式。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | 盈亏平衡通胀率(10Y-TIPS)日变化、CPI发布vs预期差 | CPI超预期 → 金价先跌（加息预期→机会成本↑）后涨（通胀对冲），取决于市场更关注哪个 |
| **中** | CPI/PCE 3个月趋势、盈亏平衡通胀率趋势、原油价格趋势 | 通胀持续超预期 → 通胀预期主导，金价中期走强 |
| **长** | 10年平均CPI、核心PCE趋势、菲利普斯曲线斜率 | 高通胀regime → 金价长期有超额收益 |

**与机会成本因子的拆分**：
- 实际利率 = 名义利率 - 通胀预期
- 机会成本贡献 = 实际利率变化中由**名义利率变动**驱动的部分
- 通胀预期贡献 = 实际利率变化中由**通胀预期变动**驱动的部分
- 两者方向相反时（名义↑ + 通胀↑），净效果取决于哪个变动幅度更大

## 因子5：持仓与动量

**放大器**——不独立驱动方向，但放大其他因子的效果。CTA/trend-following策略管理约$300B+资产，仓位变化对金价有实质影响。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | 持仓量(OI)变化、ETF持仓日变化、关键技术位突破+RSI/MACD信号 | 价格突破200日MA + OI增加 → 趋势确认，动量放大 |
| **中** | COT投机净多头占比（历史分位数）、ETF持仓变化速率 | COT净多头 > 90%分位 → 拥挤，短期回调风险高 |
| **长** | 全球黄金ETF总持仓趋势、黄金在多资产组合中权重变化 | ETF持续增持 → 长线资金进场，中期支撑 |

**持仓量信号解读**：

| 价格 | 持仓量(OI) | 信号 |
|------|-----------|------|
| ↑ | ↑ | 新多头入场，趋势确认 |
| ↑ | ↓ | 空头平仓驱动，趋势衰竭 |
| ↓ | ↑ | 新空头入场，下跌确认 |
| ↓ | ↓ | 多头平仓驱动，下跌衰竭 |

## 因子6：结构性需求

短期几乎不可见，但在长期是金价中枢的决定性力量。2022年以来的金价牛市，结构性需求的贡献可能被低估了。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | — | — |
| **中** | 全球央行季度购金量、央行月度储备变化 | 央行购金 > 1000吨/年 → 金价有"央行底" |
| **长** | 美元外储占比趋势、央行黄金占外储比例 | 去美元化加速 → 金价长期中枢上移；美元外储占比从65%→55% → 金价中枢上移30-50% |

## 因子7：银价专用

银价 = 金价驱动 + 银价独立驱动。上面6个因子解释金价，银价还有两个独立维度：

### 7a 工业需求

白银50%+需求是工业（光伏、电子、焊料、EV），与经济周期正相关。这与黄金的"避险"属性相反——衰退时金价涨但银价可能跌。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | — | — |
| **中** | 白银年度供需平衡、LBMA/COMEX白银库存趋势、光伏装机量增速 | 供不应求 + 库存下降 → 银价相对金价走强 |
| **长** | 光伏累计装机量、EV渗透率、半导体需求增速 vs 白银矿产供给增速 | 需求增速持续超过供给增速 → 白银结构性牛市 |

白银供需错配：白银70%来自有色金属伴生矿，供给弹性低。但光伏+EV+AI半导体需求结构性增长。连续4年供不应求，库存持续下降。

### 7b 金银比均值回归

金银比历史均值约60-65，但波动范围30-100。极端值会均值回归。

| 时间尺度 | 核心指标 | 量化方式 |
|---------|---------|---------|
| **短** | 金银比当前值 vs 历史分位数 | 金银比 > 90 → 白银相对低估 |
| **中** | 金银比趋势 + 宏观环境判断 | 工业复苏期 → 比收窄（银强于金）；避险主导期 → 比扩大（金强于银） |
| **长** | 白银货币属性是否回归 | 若白银在去美元化中也被储备 → 金银比中枢下移 |

## 事件冲击 = 催化剂

不独立驱动金价方向，而是**触发其他因子快速price-in**。一个CPI数据发布可能让市场在5分钟内完成本该1周消化的预期调整。

| 时间尺度 | 表现形式 | 核心指标 |
|---------|---------|---------|
| **短** | 数据发布瞬间冲击 | 经济日历（发布时间+预期值）、发布值vs预期差、FOMC声明文本diff |
| **中** | 事件序列改变市场叙事 | 连续超预期的数据发布 → 叙事切换（如"降息叙事"→"通胀粘性叙事"） |
| **长** | 制度性事件改变regime | 极低概率但极高影响（金本位讨论、SWIFT替代、布雷顿森林级变化） |

**事件冲击的传导路径**：
```
CPI发布超预期
  → 催化剂触发
  → 机会成本（加息预期升温，实际利率预期↑）→ 金价短期承压
  → 通胀预期（通胀预期↑）→ 金价中期支撑
  → 净效果取决于：市场当前更关注"加息"还是"通胀"
```

## 因子间关系

```
               通胀预期
                  │
                  ▼
财政赤字 ──→ 机会成本 ──→ 金价
                  ↑              ↑
结构性需求        │          避险需求
  (央行购金) 货币(正交)──┘
                  ↑              ↑
             机会成本∩货币    事件冲击
             (利率→美元)    (催化所有因子)

持仓动量 = 放大器（不独立驱动，放大其他因子效果）
事件冲击 = 催化剂（触发其他因子快速price-in）

───────── 银价额外 ─────────
工业需求 ──→ 银价（独立于金价的部分）
金银比均值回归 ──→ 银价相对金价
```

### 因子主导权切换

机会成本因子是常态主导（~50-60%解释力），但特定regime下其他因子升为主导：

| 市场regime | 主导因子 | 典型时期 |
|-----------|---------|---------|
| 加息周期末期 | 避险需求升主导 — 衰退担忧 | 2018Q4, 2023Q3 |
| 通胀失控期 | 通胀预期升主导 | 2022H1 |
| 去美元化加速期 | 结构性需求升主导 | 2022-至今 |
| 流动性危机 | 避险需求短期**反转** — 抛售变现 | 2020年3月 |

## 双层交互规则

因子层（方向判断）与技术面层（时机验证）的协同机制：

### 交互模式

| 场景 | 因子层 | 技术面层 | 综合结论 |
|------|--------|---------|---------|
| **信号共振** | 看多(↑) | 趋势多头 + RSI正常 | 高确信度，执行 |
| **信号背离** | 看多(↑) | 趋势多头但RSI>70超买 | 看多但等回调，不追高 |
| **趋势冲突** | 看多(↑) | MA空头排列 | 暂缓，等待技术面转多确认 |
| **因子中性** | 中性(—) | 趋势明确 | 轻仓顺技术面方向，因子层不作为主要依据 |
| **极端背离** | 看多(↑) | MACD顶背离 | 警惕转折，因子信号可靠性降低 |

### 技术面优先级

异动时技术面信号比因子信号更快：

1. **垂直拉升/跳水**（1min > 0.3%）→ 先按事件冲击处理，再归因
2. **关键位突破**（日线级别支撑/阻力放量突破）→ 趋势可能转变，因子信号需重新评估
3. **技术形态完成**（头肩顶/底、双顶/底）→ 即使因子信号未变，也需警惕

## 短期异动归因逻辑

当金价出现短期异动时，按以下优先级归因：

| 现象 | 归因优先级 | 判断方法 |
|------|-----------|---------|
| 金、银**同向**急涨/跌 | 机会成本 → 避险需求 | 检查TIPS/DXY/VIX是否同步异动 |
| 金涨、银**不动或反方向** | 结构性需求（央行购金）或 持仓动量（CTA加仓） | 检查COT/央行公告 |
| **金银比**快速扩大/缩小 | 银价专用（均值回归） | 金银比偏离均值程度+宏观环境 |
| 金价**垂直拉升**（1min > 0.3%） | 事件冲击 | 检查经济日历是否有数据发布 |
| 金价**阶梯式**30min缓慢推升 | 持仓动量（订单流驱动） | 检查OI是否持续增加 |
| 金价跌但实际利率不变 | 货币因子独立贡献 | 检查DXY异动但TIPS平稳 |
