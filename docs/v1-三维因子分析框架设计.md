# 三维因子分析框架设计

## 一、核心问题

当前看行情经常遇到的情况：

| 场景 | 问题 |
|------|------|
| 白银今天跌了 8%，但上周还在涨 | 这是短期情绪还是趋势反转？ |
| TIPS 在降，但 DXY 在涨 | 机会成本利多，货币利空，哪个主导？ |
| 上周判断看多，今天问我又要重头分析 | 哪些因子变了，哪些没变？ |

根源：**没有把"时间维度"和"因子方向"拆开。**

---

## 二、设计思路

每个因子不再只有一个方向，而是拆成**三个时间维度**的信号：

```
一个因子 = 短期信号 + 中期信号 + 长期信号
              ↓           ↓           ↓
          事件/情绪    周期/趋势   结构/大方向
```

### 举例：机会成本因子

```
TIPS 当前值 2.11%，20日趋势 down → 机会成本整体利多

拆开看三个维度：

短期（近3天）：TIPS 日变化 0bp → 短期无变化，中性
中期（近20天）：TIPS 持续下行 -2bp/天 → 中期利多趋势明确
长期（近60天）：TIPS 处于降息周期尾声 → 长期利多但可能接近尾声
```

### 举例：白银 6/5 暴跌

```
机会成本因子：
  短期：非农 +172K → 加息预期飙升 → 短期强烈利空 ← 这是当天的触发源
  中期：TIPS 连续下行 20天 → 中期利多（但被短期压制）
  长期：降息周期末期 → 长期利多（但空间有限）
```

这样一看就清楚：**短期利空强烈，但中长期的趋势其实还没变。** 这就是"情绪/事件驱动还是趋势反转"的判断依据——短期暴力但中长期没变 → 事件冲击，等待消化；短中长期同向 → 趋势反转。

---

## 三、三周期定义

| 维度 | 时间窗口 | 关注指标 | 含义 | 典型影响因素 |
|------|---------|---------|------|-------------|
| **短期 (Short)** | 1~5 天 | 日变化、异动、事件 | 当前市场在炒什么 | 数据发布、突发新闻、Fed讲话、止损踩踏 |
| **中期 (Mid)** | 5~60 天 | 趋势方向、动量 | 最近的趋势是什么 | 加息预期、美元走势、金银比均值回归 |
| **长期 (Long)** | 60 天+ | 周期位置、大方向 | 大环境是牛是熊 | 降息周期、去美元化、央行购金、通胀中枢 |

### 各因子时间维度的典型信号源

| 因子 | 短期(1-5天) | 中期(5-60天) | 长期(60天+) |
|------|------------|-------------|------------|
| 机会成本 | TIPS日变化、FedWatch概率日变化 | TIPS 20日趋势、名义利率趋势 | 实际利率regime、点阵图方向 |
| 货币 | DXY日变化 | DXY vs MA20、60日趋势 | 美元外储占比、去美元化 |
| 避险需求 | VIX日变化、异动事件 | VIX 20日均值、信用利差趋势 | 地缘风险中枢、系统性风险 |
| 通胀预期 | 原油日变化、盈亏平衡日变化 | CPI趋势、盈亏平衡 20日趋势 | 通胀regime、货币供应量 |
| 持仓动量 | OI日变化、价格+OI组合信号 | COT分位、ETF持仓趋势 | 配置权重变化 |
| 结构性需求 | —（无短期数据） | — | 央行季度购金趋势 |
| 银价专用 | 金银比日变化 | 金银比 20日趋势、分位数 | 光伏/工业需求长周期 |

## 四、使用方式——场景分类

关键应用：**通过三周期信号的一致性判断当前属于什么场景。**

### 场景判断规则

```
检查三个维度信号：
  短期信号 vs 中期信号 vs 长期信号

┌─────────────────────────────────────────────────────────────┐
│  场景1: 趋势驱动                                            │
│  条件: 短/中/长 同向且强度一致                                │
│  处理: 顺势，技术面找入场                                    │
│  例: TIPS短(利空0.6) + 中(利空0.7) + 长(利空0.5) = 利率全面看空金银 │
├─────────────────────────────────────────────────────────────┤
│  场景2: 情绪/事件冲击                                        │
│  条件: 短期强烈(>0.7) + 中/长 方向不变或相反                    │
│  处理: 等情绪消退，不做趋势判断                                │
│  例: 白银6/5：短(利空0.9) + 中(利空0.3) + 长(利多0.2) = 非农冲击  │
├─────────────────────────────────────────────────────────────┤
│  场景3: 趋势中的回调                                         │
│  条件: 短期逆中长期方向 + 短期是情绪性                          │
│  处理: 回调企稳后加仓                                        │
│  例: 白银涨了1个月(中利多)，今天跌2%(短利空)，但驱动因子没变       │
├─────────────────────────────────────────────────────────────┤
│  场景4: 可能转折                                             │
│  条件: 短期逆中长期方向 + 短期是基本面驱动                        │
│  处理: 减仓/对冲，等待确认                                    │
│  例: 降息周期(长利多)，但非农改变加息预期(短利空可持续)            │
├─────────────────────────────────────────────────────────────┤
│  场景5: 震荡/噪音                                            │
│  条件: 短/中/长 方向混乱，无主导因子                            │
│  处理: 观望                                                  │
└─────────────────────────────────────────────────────────────┘
```

## 七、与现有分析的配合

这个设计跟 SOP 现有的 Step 4 场景分类逻辑**不冲突，反而是它的数据基础**。当前 Step 4 的判断流程（4a检查短期异常 → 4b检查中长期 → 4c冲突检查 → 4d一致性检查）本质上就是在做三周期信号的分析，只是目前没有显式数据支持。

加上三周期信号后，Step 4 的判断就不需要凭感觉了，而是直接读数：

```
4a: 短期是否有因子 > 0.7  → 直接看 signals.short.strength
4b: 中期和长期是否同向    → 直接比较 signals.mid 和 signals.long
4c: 短期与中长期冲突？    → 直接看方向是否一致
```
