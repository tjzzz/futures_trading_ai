## 一、接入方案选型

### 技术选型：天勤 TqSDK v3.10.0

对比过的方案：

| 方案 | 结论 | 原因 |
|------|------|------|
| **天勤 TqSDK** | ✅ **采用** | 本地 Python SDK，免费模拟盘，直接支持 SHFE 金银，一行代码下单 |
| 同花顺 SuperMind | ❌ 不适合 | 策略跑在云端，AI agent 无法直接控制 |

| 掘金量化 | ❌ 依赖客户端 | 必须装客户端，集成不顺 |

## 二、系统架构

```
行情推送(TqSDK WebSocket) ─每秒→ 引擎 → 策略 → 风控 → 下单
                                         ↓
                                    state.json (每秒写入)
                                         ↓
                                  Flask看板 (端口8083)
```

### 模块结构

```
trading/
├── __init__.py        # 包入口
├── config.py          # 合约参数、风控阈值、资金配置
├── engine.py          # 交易引擎（wait_update 驱动，秒级行情）
├── order.py           # 订单/持仓管理（封装 TqSDK API）
├── risk.py            # 风控（止损、仓位、连续亏损冷却）
├── strategy.py        # 策略（品种感知：金/银不同参数）
├── run.py             # 运行入口（--dry 模拟模式）
├── backtest.py        # 回测模块（基于历史K线数据）
├── state_writer.py    # 状态写入（供看板读取）
├── web.py             # Flask 实时看板 (端口8083)
├── dashboard.html     # 看板 HTML 页面
├── test_connection.py # 连接测试脚本
└── test_module.py     # 离线单元测试
```

## 三、策略逻辑

### 日内多时间框架趋势跟踪

```
15分K线 ── 定主方向（MA排列 + MACD + 布林带 + 动量）
   │
5分K线 ──── 找入场点（价格回调到 MA20 附近）
   │
1分K线 ──── 确认（成交量活跃）
   │
收盘前 14:50 ── 强制平仓（日内交易无隔夜）
```

### 品种差异参数

| 参数 | 沪金 gold | 沪银 silver | 含义 |
|------|-----------|------------|------|
| volatility_factor | 1.0 | 2.5 | 动量检测阈值缩放 |
| score_threshold | 3 | 2 | 趋势判定分数门槛 |
| stop_loss_pct | 1.5% | 2.5% | 单笔止损比例 |
| entry_ma_deviation | 0.5% | 1.0% | 入场 MA20 偏离容差 |

### 信号评分规则

```
多头加分:
  - 均线多头排列（价格>MA5>MA20）        +2
  - MACD > 0 且上升                       +2
  - 柱状图放大（趋势加强）                +1
  - 布林带位置 > 0.3                      +1
  - 急涨动量（3周期涨幅超阈值）          +2
  - 趋势一致性（短中期同向）              +1

空头对标对称。总分 >= score_threshold 且明显偏向一侧时确定方向。
```

## 四、风控规则

| 规则 | 值 |
|------|-----|
| 单品种保证金占用上限 | ≤ 总资金 20% |
| 总保证金占用上限 | ≤ 总资金 30% |
| 单笔止损（金/银） | 1.5% / 2.5% |
| 单日最大亏损 | 4% |
| 连续亏损暂停 | 3 次 → 冷却 30 分钟 |
| 收盘强制平仓 | 14:50（日盘）/ 02:25（夜盘） |

## 六、运行方式

### 连接测试
```bash
/usr/local/opt/python@3.11/libexec/bin/python3 trading/test_connection.py
```

### 启动交易引擎
```bash
# 模拟模式（只看信号不下单）
python3 trading/run.py --dry

# 实盘模式（自动交易）
python3 trading/run.py
```

### 启动实时看板
```bash
python3 -m trading.web --port 8083
# 访问 http://localhost:8083
```

### 回测
```bash
# 沪金回测
python3 -m trading.backtest --symbol gold --daily

# 沪银回测
python3 -m trading.backtest --symbol silver --daily
```

### Python 环境
```bash
# 使用系统 Python 3.11（managed Python 3.13 有 numpy 签名问题）
/usr/local/opt/python@3.11/libexec/bin/python3
```
