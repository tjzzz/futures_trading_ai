# V1 新闻事件模块设计方案

> 基于事件生命周期的新闻采集与监控系统。
> 替代 V0 四象限归因，实现专题事件追踪 + 实时新闻流的双层架构。

---

## 一、定位与目标

### 解决的核心问题

| 问题 | 现状 | 目标 |
|------|------|------|
| 噪音太多 | 67% 新闻与交易无关 | 过滤到 < 30% 无关新闻 |
| 无事件追踪 | 每条新闻独立过期，不知是同一事件的延续 | 按事件生命周期组织，追踪来龙去脉 |
| 归类精度低 | 关键词单次命中即归类，误报率高 | 多关键词组合 + 排除规则，精度 > 70% |
| 缺少预警 | 无数据发布预期 vs 实际对比 | 经济日历自动匹配，超预期自动标记 |

## 二、数据覆盖

### 层 A：实时新闻流（信号 + 警报）

**金银/贵金属**
- 金银价格异动 → 触发因子排查
- COMEX/LBMA 仓单变化
- ETF（GLD/SLV）大额申赎

**宏观数据（最重要）**
- 非农 / CPI / PCE / GDP / 初请
- FOMC 决议 + 点阵图
- Fed 官员讲话（鹰/鸽分类）

**地缘政治**
- 伊朗/中东（霍尔木兹海峡、核谈判）
- 俄乌冲突
- 中美关系（关税/制裁）
- 台海局势

**能源/商品**
- 原油（OPEC+ 决定、库存、价格异动）
- 铜/工业金属（需求信号）
- 供应链中断

**国内市场**
- 中国央行政策（LPR、降准降息）
- 沪金/沪银持仓异动
- 人民币汇率波动

### 层 B：专题事件（深度追踪）

| 专题 | 覆盖范围 | 更新频率 | 默认激活 |
|------|---------|:--------:|:--------:|
| **Fed 政策路径** | 加息预期，FOMC 日程，官员讲话，数据依赖 | 每次数据/讲话 | ✅ 永久 |
| **中东/伊朗局势** | 停火谈判，霍尔木兹，油价传导，核问题 | 每天 | ✅ 当前活跃 |
| **中国复苏/刺激** | 政策宽松，PMI，社融，房地产 | 每周 | 🔲 待定 |
| **金银持仓/资金流** | ETF 流向，COT 持仓，交易所库存 | 每周 | 🔲 待定 |
| **经济日历** | 本周重要数据发布排期 | 每日更新 | ✅ 永久 |

## 三、数据源架构

### 3.1 源清单

```
新闻事件采集器 (collectors/)
├── akshare_news.py      ← ★ Phase 1 主源（AKShare/金十数据 + 华尔街见闻 + 百度财经）
│   ├── 金十数据 js_news(indicator='最新资讯')  ← 实时财经快讯
│   ├── 金十数据 js_news(indicator='最新数据')  ← 最新经济指标
│   ├── 华尔街见闻 macro_info_ws(date)           ← 结构化宏观日历(含预期 vs 实际)
│   └── 百度财经 news_economic_baidu()           ← 经济指标日历(备用)
│
├── news_rss.py          ← 兜底（CNBC/MarketWatch RSS 降级为备用）
│
├── [待建] gdelt.py      ← GDELT 全球新闻扫描（Phase 2）
│
└── [待建] topics.py     ← 专题事件汇聚器（Phase 2）
```

### 3.2 源详情

| 源 | 方式 | 频次 | 费用 | 状态 | 价值 |
|----|------|:----:|:----:|:----:|------|
| **金十数据** (akshare) | API | **5~15分钟** | 免费 ✅ | **已上线** | 中文实时快讯，直接关联七因子 |
| **华尔街见闻** (akshare) | API | 每日1次 | 免费 ✅ | **已上线** | **含今值 vs 预期 vs 前值**，直接可对比超预期程度 |
| **百度经济日历** (akshare) | API | 每日1次 | 免费 ✅ | **已上线** | 备用经济日历 |
| CNBC Markets/Economy | RSS | 30min | 免费 ✅ | 兜底 | 英文金融/宏观 |
| MarketWatch | RSS | 30min | 免费 ✅ | 兜底 | 降权使用 |
| Reuters (reut.rs) | RSS | 30min | 免费 ✅ | 待接入 | 大宗商品权威RSS |
| **GDELT** | API | 15min | 免费无限 ✅ | **待建** | 全球新闻地毯式扫描 |

### 3.3 经济日历工作流

```
akshare.macro_info_ws(today)
  → 美国重要性 3+ 的事件
  → 对比今值 vs 预期
  → 超预期判断
  → 写入 event_tracker.json（类型: data_release）
```

**超预期判断规则：**
- 今值 > 预期 × 1.1 → 超预期偏多
- 今值 < 预期 × 0.9 → 低于预期偏空
- 具体方向还需看指标性质（CPI↑利空，初请↓利多）

## 四、事件生命周期模型

### 4.1 事件结构

```json
{
  "event_id": "fed_rate_path_2026q2",
  "title": "Fed加息预期逆转 — 非农冲击",
  "type": "policy_shift",
  "status": "active",
  "severity": "high",
  "factor_tags": ["opportunity_cost", "currency"],
  "started_at": "2026-06-05",
  "expected_expiry": "2026-06-17",
  "sources": ["rss", "gdelt", "calendar"],
  "key_levels": {
    "fed_hike_prob": 0.65,
    "tips_10y": 2.11,
    "dxy": 99.22
  },
  "timeline": [
    {
      "date": "2026-06-05",
      "headline": "美国5月非农 +172K vs 预期 +85K",
      "detail": "前值上修93K。加息概率从48%飙至65%",
      "source": "calendar",
      "impact": "金银暴跌，白银-8%"
    },
    {
      "date": "2026-06-08",
      "headline": "非农后效延续，DXY突破100",
      "detail": "沪银午盘跌超8%，COMEX白银跌破$68",
      "source": "rss",
      "impact": "金银续跌，白银-8%"
    }
  ],
  "next_focus": "6/10 CPI数据 / 6/17 FOMC点阵图",
  "narrative_change": "从降息预期 → 加息预期重燃"
}
```

### 4.2 事件类型（决定生命周期和升级规则）

| 类型 | 含义 | 典型生命周期 | 触发升级到标准分析的条件 |
|------|------|-------------|-----------------------|
| `data_release` | 宏观数据发布 | 数据前3天→发布→消化1-3天 | 超预期 > 1σ 且涉及主导因子 |
| `geo_political` | 地缘政治事件 | 数周到数月 | 持续性 > 3天且影响避险因子 |
| `policy_shift` | 央行/政策转向 | 数周 | 首次出现即可升级 |
| `price_anomaly` | 价格异动 | 数小时到数天 | 金银日波动 > 2% |
| `supply_shock` | 供给冲击 | 数天到数周 | 原油波动 > 5% |
| `institutional` | 机构/资金流向 | 周度 | COT/ETF持续异动 |

### 4.3 事件生成规则

```
新新闻流入
  ↓
匹配活跃事件（按 事件title / 关键词）
  ├─ 匹配 → 追加到 timeline，更新 key_levels
  └─ 不匹配 → 判断是否值得开新事件
       ├─ 是 → 创建新事件（类型从关键词推断）
       └─ 否 → 放入 latest_feed 但不产生事件

事件状态变更：
  active → resolved ← 预期过期时间到了 或 事件已无新进展3天
  active → archived ← resolved 后7天自动归档
```

### 4.4 事件过期规则

| 条件 | 动作 |
|------|------|
| 超过 expected_expiry + 3天无更新 | → resolved |
| 超过 7天无更新（非地缘类） | → resolved |
| 地缘事件超过 14天无更新 | → resolved |
| resolved 后 7天 | → archived（从活跃事件列表移除，保留在完整事件库） |

## 五、采集频次汇总

| 采集器 | 频次 | 说明 |
|--------|:----:|------|
| `rss.py` | 30min | 4个RSS源顺序抓取，低开销 |
| `gdelt.py` | 15min | API轮询，免费无限 |
| `calendar.py` | 每日7:30 | 获取当日+未来7天事件排期 |
| `topics.py` | 每次新闻新数据 | 非独立采集，从以上流中汇聚 |

## 六、输出结构

```
data/events/
├── event_tracker.json        ← 活跃事件列表（核心输出）
├── latest_feed.json          ← 最新100条新闻流（与当前兼容）
├── calendar_cache.json       ← 经济日历缓存（含今值vs预期对比）
└── monitor_state.json        ← 采集器状态（已有）
```

`event_tracker.json` 直接喂入 `compute_factors.py`，每个事件标注 `factor_tags`，与因子模型同口径。
