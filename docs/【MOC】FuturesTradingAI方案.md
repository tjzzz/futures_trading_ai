# FuturesTradingAI — V1 方案设计

> 方案讨论与设计文档。实现细节在 `futures_trading_ai/` 项目中。

---

## 为什么想要做个AI交易系统

1. **服务于自己**：辅助自己做期货交易（以后可扩展到资产管理）
   1. **标的筛选** — 结合宏观经济，判断当前哪些品种适合入手
   2. **仓位管理** — 重大事件预警、波动归因、加减仓建议
   3. **短线辅助** — 多空判断、入场/离场时机
   4. **交易复盘** — 每天对话复盘，记忆能积累
2. **模块稳定后产品化** — 输出能力服务于别人

---

## V0 → V1 核心转变

| 维度 | V0 现状 | V1 目标 |
|------|---------|---------|
| 交互 | Dashboard + 飞书查命令 | 飞书推送 + Web 应用 + Claude 对话 |
| 记忆 | 无 | 分层持久化（Agent + Obsidian） |
| 知识库 | 无 | Wiki 知识库外挂 |
| 闭环 | 数据→分析→展示 | 选标的→建仓→持仓→归因→复盘 |
| 主动性 | 被动等用户查 | 晨报推送、异动提醒、复盘 |
| 个性化 | 通用分析 | 针对持仓和偏好 |

# 整体架构

V1 由四个核心模块组成，用户通过飞书和 Web 两个入口交互，知识库作为独立模块对外提供服务：

```
                    ┌──────────────────┐
                    │      用户         │
                    └────────┬─────────┘
                             │
            ┌────────────────┼──────────────────┐
            │                │                  │
    ┌───────▼───────┐ ┌─────▼──────┐          │
    │  飞书机器人     │ │  Web 应用   │          │
    │  (即时/推送)    │ │ (深度分析)  │          │
    └───────┬───────┘ └─────┬──────┘          │
            │                │                 │
            └────────────────┼─────────────────┘
                             │
                    ┌────────▼────────┐   ┌──────────────────┐
                    │  后端 AI 引擎    │◄──│  知识库 Wiki      │
                    │  (Agent API)    │   │  (结构化知识)     │
                    │                 │   └──────────────────┘
                    │  工具层:        │
                    │  data_query     │
                    │  记忆系统       │
                    │  Claude 推理    │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │  V0 数据基础层   │
                    │  (采集器/中台)   │
                    └─────────────────┘
```

四个模块各自职责：

| 模块 | 定位 | 面向谁 |
|------|------|--------|
| [[#模块一：飞书机器人]] | 即时触达、轻量交互 | 你（手机端） |
| [[#模块二：Web 应用]] | 深度分析、可视化 + 聊天 | 你（桌面端） |
| [[#模块三：后端 AI 引擎]] | 核心服务，被飞书和 Web 调用 | 系统内部 |
| [[#模块四：知识库 Wiki]] | 结构化知识沉淀，供引擎查询、你浏览 | 你 + AI |

# 模块一：飞书机器人

**定位**：即时的、轻量的触达入口。适合"瞄一眼"和"别忘掉"的场景。

### 推送场景

| 推送 | 触发条件 | 内容 |
|------|----------|------|
| **早报卡片** | 每日开盘前定时 | 宏观速览 + 持仓点评 + 今日关注 |
| **异动预警** | 指标突破阈值 | 品种 + 当前值 + 阈值 + 简要解读 |
| **事件提醒** | 重大宏观事件前 | 事件 + 时间 + 预期影响 |

### 交互场景

| 查询 | 回复 |
|------|------|
| `持仓` | 当前持仓卡片（品种/方向/手数/浮动盈亏） |
| `黄金` / `白银` | 品种实时行情 + 简要观点 |
| `宏观` | 关键宏观指标摘要 |

**设计原则**：不做复杂交互。所有深度分析引导到 Web 应用。

---

# 模块二：Web 应用

**定位**：深度分析入口。行情可视化 + 绩效报表 + 嵌入式 Claude 聊天。

### 功能布局

```
┌─────────────────────────────────────────────┐
│  侧边导航          │  主区域                 │
│                    │                        │
│  📊 行情概览       │  ┌──────────────────┐  │
│    ├ 黄金/白银趋势  │  │   Claude 聊天窗   │  │
│    ├ DXY/美债/VIX  │  │                  │  │
│    └ 金银比        │  │  "白银这周怎么看" │  │
│                    │  │   → 回答...       │  │
│  📋 持仓           │  │                  │  │
│    ├ 当前持仓       │  └──────────────────┘  │
│    └ 浮动盈亏       │                        │
│                    │                        │
│  📈 绩效           │                        │
│    ├ 月度盈亏曲线   │                        │
│    └ 品种归因       │                        │
└─────────────────────────────────────────────┘
```

**核心设计**：聊天窗是中心。用户在左侧看到什么图，就可以在聊天窗直接问。上下文贯通，不用切来切去。

### 页面清单（初版）

| 页面 | 内容 |
|------|------|
| 行情概览 | 金银/DXY/美债/VIX 趋势图、关键指标卡 |
| 持仓 | 当前持仓列表、浮动盈亏 |
| 绩效 | 月度盈亏曲线、品种归因 |

**知识库浏览**直接通过 Obsidian，Web 只展示简单报表。

# 模块三：后端 AI 引擎

**定位**：被飞书和 Web 调用的核心服务。封装 trade-macro agent 为 API。

### 内部结构

```
后端 AI 引擎
├── Agent 服务            ← trade-macro agent 的逻辑
│   ├── System prompt     ← agent.md 内容
│   ├── 工具链           ← data_query、文件读写、Wiki 检索
│   └── 会话管理         ← 多轮对话上下文
│
├── 数据工具层
│   ├── data_query.py    ← 行情/宏观/事件/新闻查询
│   └── 分析引擎         ← 可选的 V0 analysis 调用
│
├── 记忆系统
│   ├── Agent 系统记忆   ← zzzheng.AI/workspace/memory/
│   ├── 用户状态         ← wiki_trade/memory/ (profile/持仓/历史)
│   └── 决策沉淀         ← wiki_trade/memory/ (决策/宏观备忘)
│
└── Wiki 检索
    └── 从 wiki_trade/wiki/ 查询相关知识
```

### API 接口（初版）

| 接口 | 输入 | 输出 |
|------|------|------|
| `POST /chat` | 消息 + 上下文 | Agent 回复 |
| `GET /snapshot` | — | 当前行情快照 |
| `GET /positions` | — | 持仓信息 |
| `GET /analysis` | 品种/周期 | 分析报告 |

# 模块四：知识库 Wiki

**定位**：结构化沉淀交易知识和经验。AI 引擎检索使用，你在 Obsidian 中浏览/编辑。边用边填，逐步积累。

### 目录结构

```
wiki_trade/wiki/
├── index.md                    ← 入口目录
├── 宏观框架/                   ← 分析市场的理论框架
│   ├── 四象限分析.md
│   └── 金银驱动因子体系.md
├── 指标手册/                   ← 关键指标解读方法
│   ├── TIPS.md
│   └── 金银比.md
├── 经验模型/                   ← 从交易中提炼的规律
│   └── （待填充）
└── 交易规则/                   ← 纪律和公式
    └── （待填充）
```

### 内容来源

| 来源 | 方式 |
|------|------|
| V0 analysis/engine 规则逻辑 | AI 提取为 Wiki 文档 |
| decisions.md 反复出现的有效/无效模式 | AI 复盘后提炼 |
| 你主动补充的交易认知 | 你直接写 |

### 使用规则

1. AI 分析某个指标或场景时，先查 Wiki 确认框架
2. 发现新规律 → AI 写入经验模型
3. 你发现不对或想补充 → 直接在 Obsidian 编辑

# 三层分离

整体架构的四个模块，按物理存储位置分为三层：

```
┌──────────────────────────────────────────────────────────┐
│  交互层                                                  │
│  ┌──────────────────┐  ┌──────────────────┐              │
│  │  飞书机器人       │  │  Web 应用         │              │
│  │  (V0 feishu/)    │  │  (新建前端项目)    │              │
│  └──────────────────┘  └──────────────────┘              │
├──────────────────────────────────────────────────────────┤
│  服务层                                                  │
│  ┌──────────────────┐  ┌──────────────────┐              │
│  │  后端 AI 引擎     │  │  知识库 Wiki      │              │
│  │  (zzzheng.AI +   │  │  (wiki_trade/    │              │
│  │   futures_trading_ai) │   wiki/)        │              │
│  └──────────────────┘  └──────────────────┘              │
│                                                          │
│  记忆 & 数据层                                            │
│  ┌──────────────────┐  ┌──────────────────┐              │
│  │  记忆存储         │  │  V0 数据基础层    │              │
│  │  (zzzheng.AI/    │  │  (futures_       │              │
│  │   workspace +    │  │   trading_ai/    │              │
│  │   wiki_trade/    │  │   data/)         │              │
│  │   memory/)       │  │                  │              │
│  └──────────────────┘  └──────────────────┘              │
└──────────────────────────────────────────────────────────┘
```


| 层 | 内容 | 存放位置 | 谁读写 |
|----|------|----------|--------|
| **交互层** | 飞书机器人逻辑、Web 前端代码 | `futures_trading_ai/feishu/` + 新建前端项目 | 代码维护 |
| **服务层** | Agent 推理、工具链、Wiki 知识 | `zzzheng.AI/agents/trade-macro/`（Agent 配置 + 系统记忆） + `wiki_trade/wiki/`（知识库） + `futures_trading_ai/tools/`（数据工具） | AI 推理 + 你编辑 Wiki |
| **记忆层** | Agent 系统记忆、用户状态、交易流水 | `zzzheng.AI/agents/trade-macro/workspace/memory/`（系统记忆） + `wiki_trade/memory/`（用户画像/持仓/决策/宏观备忘） | AI 自动维护 + 你手动编辑 |
| **数据层** | V0 采集器、数据中台 | `futures_trading_ai/collectors/` + `data/` | 后台自动运行 |

### 设计原则

- **Agent 层可替换** — 后期换成别的模型或做成产品时，只需换 Agent 配置和系统记忆，知识库和工程代码不受影响
- **知识库 + 存储集中** — 所有交易相关的知识和记忆集中在 `wiki_trade/` 下，不影响 vault 原有目录
- **项目工程纯净** — `futures_trading_ai/` 是纯代码项目，不掺杂个人信息
