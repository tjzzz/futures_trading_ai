# 金银价格驱动因子框架

> 基于金融经济学第一性原理的因子体系
> 日期：2026-06-03 | 版本：1.0

---

## 一、核心定价模型

### 黄金的零息资产属性

黄金不产生利息、没有信用风险、没有现金流，本质上是一个**零息资产**。因此持有黄金的唯一成本 = 放弃的替代投资收益率（机会成本）。

```
金价 = f(机会成本, 央行购金, 避险与流动性, 资金流, 供给约束) + 事件冲击
```

### 白银的双重属性

白银与黄金共享货币属性，但额外有**工业属性**，因此定价逻辑有两个叠加层：

```
银价 = 金价 × 金银比⁻¹ + 工业需求溢价 + 供给约束溢价
```

其中金银比本身受工业周期影响。

## 二、因子详解

### 因子1：机会成本（权重 ~40%，历史 ~50-60%，2022 年后结构性下降）

**因果机制**：
```
实际利率 ↑ → 持有黄金的机会成本 ↑ → 投资者抛金追债 → 金价 ↓
```

这是黄金定价的单变量最强因子。需要注意的是，2022 年以来央行大规模购金（年均 ~1000 吨 vs 此前 ~500 吨）削弱了机会成本的主导地位，从 ~55% 降至 ~40% 的预估权重。

**测量方式**：

| 层次 | 核心指标 | 辅助指标 | 数据源 | 频率 |
|:----:|:---------|:---------|:--------|:----:|
| 短周期（分钟~小时） | DXY 实时变化 | US10Y 实时变化 | Yahoo Finance | 5min |
| 中周期（日~周） | TIPS 10Y 收益率 | 收益率曲线形态（2-10Y 利差） | FRED + Treasury | 日 |
| 长周期（月~年） | FedWatch 利率路径 | 实际利率 regime（正/负） | CME FedWatch | 日 |

**因子正交化说明**：

```
TIPS 10Y（实际利率）是最优单一代理变量，因为它已经包含了：
  ① 名义利率水平
  ② 通胀预期（盈亏平衡通胀率 BEI ≈ 名义 US10Y − TIPS 10Y）

但以下情况需要拆分看待：
  - TIPS 有 T+2 延迟，实时看 US10Y + DXY 组合
  - DXY 和 TIPS 历史相关 ~0.7，但 2024-2026 年欧日央行政策分化使相关性下降
  - 建议保留 DXY + TIPS 两个指标，用 PCA 提取正交因子
```

### 因子2：央行购金（权重 ~15%，2010 年后新增的结构性力量）

**因果机制**：
```
央行储备多元化 → 持续买入实物黄金 → 金价底部抬升 → 改变金价对实际利率的敏感度
```

这是 2010 年后出现的**新定价力量**，传统模型完全没有考虑。2022 年俄乌冲突后加速——西方冻结俄罗斯美元储备 → 全球央行（尤其是中国、印度、波兰、土耳其）加速去美元化。

| 层次 | 核心指标 | 数据源 | 频率 | 当前状态 |
|:----:|:---------|:--------|:----:|:--------:|
| 季/年 | WGC 央行购金净量（吨/季） | 世界黄金协会 | 季 | ❌ 未接入 |
| 季/年 | 中国央行黄金储备月度变化 | 人行官网 / WGC | 月 | ❌ 未接入 |
| 季/年 | 全球黄金储备总量趋势 | WGC | 季 | ❌ 未接入 |

**关键信号阈值**：
- 年化购金 > 800 吨 → 强支撑（牛市基底）
- 年化购金 500-800 吨 → 中性支撑
- 年化购金 < 500 吨 → 结构性支撑减弱

### 因子3：避险与流动性（权重 ~20%，日常偏低，危机时刻 > 50%，需状态切换）

**因果机制（需区分两种类型）**：

```
类型A：流动性避险危机
  金融中介崩溃 → 需要现金 → 抛售一切 → 黄金也跌
  典型：2008雷曼、2020年3月（黄金从1700→1470）
  信号：VIX > 35 + 信用利差急剧扩大 + FRA-OIS 飙升

类型B：地缘/通胀避险危机
  地缘冲突/货币贬值 → 黄金作为价值储存 → 金价上涨
  典型：俄乌冲突（2022年2月黄金从1840→2070）
  信号：VIX 15-25 + 新闻情绪骤变 + ETF 增仓
```

| 层次 | 核心指标 | 危机类型识别 | 数据源 | 频率 |
|:----:|:---------|:------------|:--------|:----:|
| 短周期 | VIX 实时 + 变化率 | VIX 突破速度 | Yahoo Finance | 5min |
| 短周期 | S&P 500 日内回撤 | 单日跌幅 > 2% | Yahoo Finance | 5min |
| 中周期 | 信用利差 IG/HY | VIX + 利差联合信号 | FRED | 日 |
| 中周期 | GLD/SLV 持仓变化 | 资金是否同时流入/流出 | 官网爬取 | 日 |
| 事件 | 新闻情感得分 | NLP 分类（冲突/政策/数据） | RSS + NLP | 30min |

**状态切换逻辑（核心机制）**：

```
┌─────────────┐     VIX ≤ 25    ┌─────────────┐
│  平静期      │ ──────────────→ │  常规波动期  │
│  避险权重 5%  │ ←────────────── │  避险权重 15% │
│  VIX < 15   │     VIX < 25    │  VIX 15-25  │
└─────────────┘                 └─────────────┘
       │                              │
       │  VIX 急剧突破 25              │  VIX > 25
       │  + 信用利差扩大               │  + 重大事件
       ▼                              ▼
┌─────────────┐                 ┌─────────────┐
│  流动性危机   │                 │  避险危机    │
│  避险权重 -5% │                 │  避险权重 30%+│
│  黄金跟跌    │                 │  黄金跟涨    │
│  VIX > 35   │                 │  VIX 25-35  │
│  + FRA-OIS↑ │                 │  + 地缘/新闻  │
└─────────────┘                 └─────────────┘
```

### 因子4：资金流（权重 ~10%，同步/略微领先）

**因果机制**：
```
聪明钱先行动 → 仓位变化 → 价格跟随（滞后 1-7 天）
```

这是**最有可能做预测**的因子，但信号较弱（信噪比低），适合作为辅助验证。

| 指标 | 领先性 | 数据源 | 频率 | 当前状态 |
|:-----|:------:|:--------|:----:|:--------:|
| GLD ETF 净流入/流出 | 领先 1-3 天 | SPDR 官网 | 日 | ❌ 未接入 |
| SLV ETF 净流入/流出 | 领先 1-3 天 | iShares 官网 | 日 | ❌ 未接入 |
| CFTC 黄金投机净多 | 领先 ~1 周 | cftc.gov | 周 | ❌ 未接入 |
| CFTC 白银投机净多 | 领先 ~1 周 | cftc.gov | 周 | ❌ 未接入 |
| 黄金期货未平仓量 | 同步 | COMEX | 日 | ❌ 未接入 |

**信号逻辑**：
- ETF 连续 3 日净流入 + 金价持平 → 看涨信号（聪明钱正在建仓）
- ETF 连续 3 日净流出 + 金价上涨 → 看跌信号（聪明钱正在出货）
- CFTC 投机净多处于历史 90% 分位以上 → 拥挤信号，反转风险增大

### 因子5：供给约束（权重 ~5%，不可忽视）

**因果机制（长期结构性）**：

```
矿产供给 ↓ / 采矿成本 ↑ → 金价成本支撑上移 → 长期价格中枢抬升
```

传统框架几乎完全忽略供给侧，但 2020 年后供给约束的影响在加大：

| 指标 | 当前状态 | 数据源 | 频率 | 当前状态 |
|:-----|:---------|:--------|:----:|:--------:|
| 全球黄金年产量 | 2018 年 Peak Gold，此后逐年下降 | WGC / USGS | 年 | ❌ 未接入 |
| 全球黄金 AISC 成本 | ~$1400/oz，持续上升 | WGC | 年 | ❌ 未接入 |
| 白银副产物占比 | ~70%+ 来自铅锌铜矿 | USGS / 行业报告 | 年 | ❌ 未接入 |
| 中国矿产出口管制 | 锑、镓、锗等影响白银副产品 | 政策追踪 | 事件 | ❌ 未接入 |

---

### 事件冲击（不可预测，用于归因）

**因果逻辑**：事件 → 改变因子的条件 → 金价反应（而非事件直接冲击金价）

```
事件类型                     → 影响的因子
─────────────────────────────────────────
FOMC 利率决议 / 点阵图       → 机会成本（FedWatch 路径变化）
CPI / PCE 超预期             → 通胀预期（BEI 变化）→ 机会成本
非农 NFP 超预期              → 增长预期 → 避险需求 + 实际利率
地缘冲突（俄乌/中东）        → 避险需求 + 央行购金（加速去美元化）
银行危机（SVB 等）           → 流动性避险（类型A）
中国/印度政策变化            → 央行购金 + 实物需求
```
