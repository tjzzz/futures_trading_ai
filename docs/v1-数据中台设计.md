# V1 数据中台设计

> 基于金银驱动因子体系的因子对齐数据模型。
> 覆盖：数据采集 → 存储 → 查询全链路。
> 实现 agent 请严格遵循本规范的接口定义。

---

## 一、设计原则

1. **因子对齐** — 所有数据按7因子组织，采集和分析用同一套分类
2. **渐进增强** — 已有数据先用起来，新采集器逐步接入
3. **干净分离** — `futures_trading_ai/` 是纯工程代码，不掺杂配置/个人信息
4. **统一入口** — 所有分析脚本通过 `data_query.py` 获取数据，不直接读文件

## 三、因子对齐数据模型

每个因子对应一个标准数据块，由 `compute_factors.py` 聚合生成。

### 3.1 输出位置

```
data/factors/current_factors.json
```

### 3.2 顶层结构

```json
{
  "updated_at": "2026-06-08 10:30:00",
  "data_source": "V0 采集 + compute_factors.py",
  "factors": {
    "opportunity_cost": { "label": "机会成本", "signal": null, "data": {} },
    "currency": { "label": "货币", "signal": null, "data": {} },
    "safe_haven": { "label": "避险需求", "signal": null, "data": {} },
    "inflation": { "label": "通胀预期", "signal": null, "data": {} },
    "positioning": { "label": "持仓动量", "signal": null, "data": {} },
    "structural_demand": { "label": "结构性需求", "signal": null, "data": {} },
    "silver_specific": { "label": "银价专用", "signal": null, "data": {} }
  },
  "events": [],
  "summary": {}
}
```

### 3.3 各因子数据字段

#### 因子1：机会成本 (opportunity_cost)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `tips_10y` | float | FRED / macro collector | 日频 | 实际利率，核心 |
| `tips_10y_change_d` | float | 计算 | 日频 | TIPS 日变化 (bp) |
| `tips_10y_trend_20d` | str | 计算 | 日频 | `up`/`down`/`flat` |
| `nominal_10y` | float | Yahoo / macro collector | 实时 | 10Y 名义收益率 |
| `nominal_10y_change_d` | float | 计算 | 实时 | 10Y 日变化 (bp) |
| `fedwatch_dots` | dict | 手动/新增采集 | FOMC会后 | 利率点阵图 |
| `fedwatch_prob` | dict | 新增采集 CME FedWatch | 日频 | 下次会议加息/降息概率 |

**示例**：
```json
{
  "tips_10y": { "value": 2.1, "source": "fred", "updated": "2026-06-07" },
  "tips_10y_change_d": -2,
  "tips_10y_trend_20d": "down",
  "nominal_10y": { "value": 4.57, "change": -0.09, "source": "yahoo" },
  "nominal_10y_change_d": -9,
  "fedwatch_prob": { "cut_25bp": 0.65, "hold": 0.30, "hike_25bp": 0.05 }
}
```

#### 因子2：货币 (currency)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `dxy` | float | Yahoo | 实时 | 美元指数 |
| `dxy_change_d` | float | 计算 | 实时 | DXY 日变化 |
| `dxy_vs_200ma` | str | 计算 | 日频 | `above`/`below`/`at` |
| `dxy_trend_60d` | str | 计算 | 日频 | `up`/`down`/`flat` |

**DXY 正交化说明**：DXY 约50%解释力与 TIPS 重叠。因子信号计算时：
- 先检查 TIPS 是否同步变动
- 若同向 → 归入机会成本，货币因子信号置为 `neutral`
- 若 DXY 独立异动 → 货币因子信号生效

#### 因子3：避险需求 (safe_haven)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `vix` | float | Yahoo / CBOE | 实时 | VIX 恐慌指数 |
| `vix_change_d` | float | 计算 | 实时 | |
| `vix_ma20` | float | 计算 | 日频 | VIX 20日均值 |
| `vix_regime` | str | 计算 | 日频 | `calm`(<15) / `moderate`(15-25) / `panic`(>25) / `crisis`(>30+利差飙升) |
| `sp500` | float | FRED | 日频 | |
| `sp500_change_d` | float | 计算 | 日频 | |
| `credit_spread` | dict | 新增采集 | 日频 | HYG-LQD 利差 |
| `ted_spread` | float | 新增采集 | 日频 | TED 利差（流动性危机指示） |

**流动性危机判定**：
```
crisis_flag = vix > 30 AND credit_spread > 500bp AND ted_spread > 100bp
→ 黄金短期偏空（抛售变现），非避险买入
```

#### 因子4：通胀预期 (inflation)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `breakeven_10y` | float | 计算 (10Y - TIPS) | 日频 | 盈亏平衡通胀率 |
| `breakeven_change_d` | float | 计算 | 日频 | |
| `cpi_mom` | float | 手动/新增 | 月度 | |
| `cpi_yoy` | float | 手动/新增 | 月度 | |
| `pce_core` | float | 手动/新增 | 月度 | 核心 PCE |
| `oil_wti` | float | 新增采集 | 实时 | 原油→通胀预期传导 |

#### 因子5：持仓动量 (positioning)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `gold_oi` | int | Yahoo | 实时或日频 | COMEX 黄金持仓量 |
| `gold_oi_change_d` | int | 计算 | 实时 | |
| `silver_oi` | int | Yahoo | 实时 | COMEX 白银持仓量 |
| `gld_holdings` | float | 新增采集 | 日频 | GLD ETF 持仓变化 |
| `slv_holdings` | float | 新增采集 | 日频 | SLV ETF 持仓变化 |
| `cot_net_long_pct` | float | 新增采集 | 周频 | COT 净多头历史分位数 |
| `shfe_gold_oi` | int | akshare | 日频 | 沪金持仓量 |
| `shfe_silver_oi` | int | akshare | 日频 | 沪银持仓量 |

**持仓量信号判定**：
```
价格↑ + OI↑ = 新多头入场，趋势确认 (看多)
价格↑ + OI↓ = 空头平仓，趋势衰竭 (警告)
价格↓ + OI↑ = 新空头入场，下跌确认 (看空)
价格↓ + OI↓ = 多头平仓，下跌衰竭 (警告)
```

#### 因子6：结构性需求 (structural_demand)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `central_bank_gold_t` | float | 手动/世界黄金协会 | 季度 | 全球央行季度购金量(吨) |
| `central_bank_gold_yoy` | float | 计算 | 季度 | 同比变化 |
| `usd_reserve_share` | float | IMF COFER | 季度 | 美元在全球外储占比 |
| `gold_reserve_share` | float | IMF COFER | 季度 | 黄金在央行外储占比 |
| `last_known_note` | str | 手动 | 按需 | 最近已知趋势描述 |

#### 因子7：银价专用 (silver_specific)

| 字段 | 类型 | 来源 | 频率 | 说明 |
|------|------|------|------|------|
| `gold_silver_ratio` | float | 计算 | 实时 | 金银比 |
| `gs_ratio_percentile` | float | 计算 | 日频 | 过去5年分位数 |
| `silver_inventory` | dict | 新增采集 | 周频 | LBMA/COMEX库存 |
| `solar_pv_growth` | float | 手动 | 季度/年度 | 光伏装机增速 |

**均值回归逻辑**：
```
金银比 > 90 → 白银相对低估，看多 silver
金银比 < 40 → 白银相对高估，看空 silver
回归速度取决于宏观环境（工业复苏期回归快，避险期回归慢）
```

## 四、compute_factors.py 规范

### 4.1 定位

从 `data_query.py` 读取原始数据，按因子模型组织为结构化 JSON。**不做方向判断**，只做数据整理。

### 4.2 接口

```bash
python tools/compute_factors.py          # 全量计算，输出到 data/factors/current_factors.json
python tools/compute_factors.py --factor opportunity_cost  # 单因子
python tools/compute_factors.py --pretty  # 带格式化输出到 stdout
```

### 4.3 内部逻辑

```python
def compute_all() -> dict:
    """
    1. 读取 data_query snapshot + history + events
    2. 计算每个因子的数据字段
    3. 计算统计量（变化、趋势、分位数等）
    4. 组装为 factors 结构
    5. 写入 data/factors/current_factors.json
    """
```

### 4.4 注意事项

- 所有时间字段统一为 `"YYYY-MM-DD HH:mm:ss"`，时区 CST (UTC+8)
- 缺失数据填 `null`，不填 0（避免误导）
- 数据来源标注 `source` 字段，便于排查
- 定时运行频率：建议配套 cron 5分钟一次

## 八、数据质量与维护

### 8.1 字段完整性检查

每个因子数据块必须包含：
- `label` — 中文名称
- `signal` — 初始为 null，由 AI 引擎填入（见后端引擎设计）
- `data` — 包含所有已配置字段（缺失填 null）
- `data.*.source` — 数据来源标注

### 8.2 数据过期标记

如果某个数据源超过正常更新间隔 2 倍仍未更新，在对应字段加标记：

```json
{
  "tips_10y": { "value": 2.1, "stale": true, "stale_since": "2026-06-05" }
}
```

### 8.3 采集状态监控

`data/events/monitor_state.json` 记录每个采集器最后运行时间和状态，新增字段：

```json
{
  "macro": { "last_run": "2026-06-08 10:00:00", "status": "ok" },
  "fedwatch": { "last_run": null, "status": "not_implemented" },
  ...
}
```
