## 一、分析前置 `step_prep`

### 1.1 数据新鲜度判断 `step_prep_freshness`

> 分析开始前，根据上次分析时间决定复用还是重跑结论。

检查 `macro_memo.md` 的 `updated` 字段（上次分析时间），对比当前时间：

| 时间差 | 复用规则 | 因子数据来源 |
|--------|---------|-------------|
| < 10 分钟 | ✅ 直接复用上次结论 | 从 `macro_memo` 读取 |
| 10~60 分钟 | ⚠️ 复用但补充说明 | 复用上次因子结论，仅刷新关键因子（机会成本/货币/避险） |
| > 60 分钟 | ❌ 必须全部重跑 | 执行完整的 SOP 流程 |
| 跨日期（隔夜） | ❌ 必须全部重跑 | 同上 + 检查隔夜事件 |

**输出标注**：在输出顶部标注数据新鲜度。
- `✅ 实时` — 10分钟内
- `⚠️ 部分数据截至 {时间}` — 10~60分钟
- `❌ 数据过期` — 超过60分钟（此时应告知用户数据需刷新）

### 1.2 推理标注规则

任何非直接从数据读取、而是基于推断得出的结论，必须标注来源类型：

| 标注 | 含义 | 示例 |
|------|------|------|
| `(数据)` | 直接从工具返回读取 | "非农 +172K (数据)" |
| `(推断)` | 基于已有数据的合理推断 | "13:30触发止损踩踏 (推断-基于成交量和价位突破)" |
| `(经验)` | 基于交易经验的判断 | "金银比跳升时白银β通常放大2-3倍 (经验)" |
| `(搜索)` | 从 WebSearch 获取 | "中东停火谈判破裂 (搜索)" |

**规则**：无数据支撑的结论必须标注来源。缺少标注 → 结论置信度自动降级。

### 1.3 上下文加载 `step_prep_context`


每次对话/分析开始，先加载：

```bash
# 1. 读取用户画像和持仓
#    (agent.md 记忆系统自动加载)
#    - user_profile.md  → 用户偏好、风险等级
#    - positions.md     → 当前持仓品种、方向、手数、成本

# 2. 读取上次宏观判断
#    - macro_memo.md    → 上次判断结论、关键点位、关注焦点

# 3. 读取框架文档
#    - 1_金银价格驱动因子体系.md → 确认分析框架
```

### 1.2 数据就绪检查 `step_prep_data`

```bash
# 获取当前行情快照
python data_query.py snapshot

# 获取因子数据
python data_query.py factors

# 获取宏观指标
python data_query.py macro
```

如果数据缺失或过期（>30min），告知用户数据延迟。

### 1.5 预判验证与权重调整 `step_prep_verify`

> 新增 · 反馈闭环机制。详见 `docs/2_预判验证与反馈闭环机制.md`

**目标**：验证上次分析预判的准确性，自动调整因子权重。

**操作**：

```bash
# 执行验证 + 统计 + 权重调整
python tools/verify_predictions.py
```

**输出**：偏差报告包含方向准确率、区间命中率、各因子准确率、调整后的权重。

**规则**：

| 场景 | 处理 |
|------|------|
| 首次分析，无历史预判 | 跳过验证，使用默认权重 |
| 有未验证预判，距上次分析 > 60分钟 | 执行完整验证流程 |
| 有未验证预判，距上次分析 < 10分钟 | 跳过验证（太新，没必要验证） |
| 验证结果显示某因子准确率 < 40% | 该因子权重自动下调，分析输出中提示"⚠️ 该因子近期准确率较低" |

**权重持久化**：调整后的权重写入 `data/factors/prediction_log.json`，后续分析自动读取。

## 二、核心分析流程（六步）`step_core`

```
Step 1: 宏观体检     → 快速扫描，了解当前状态     `step_s1_macro_check`
Step 2: 因子深度分析  → 七因子逐个读 + 查知识库    `step_s2_factor_analysis`
Step 3: 技术面验证    → 价格行为是否支持因子信号   `step_s3_technical_verify`
Step 4: 场景分类      → 判断主导周期 + 市场regime  `step_s4_scene_classify`
Step 5: 信息增量      → 事件/新闻/搜索补充        `step_s5_info_supplement`
Step 6: 场景推演      → 2-3条情景路径 + 综合输出   `step_s6_scenario_projection`
```

---

### Step 1: 宏观体检（< 30秒）`step_s1_macro_check`

**目标**：快速知道"当前是什么情况"，不深入分析。

**操作**：

```bash
python data_query.py snapshot
python data_query.py macro
```

**关注清单**：

| 指标 | 看什么 | 判断 |
|------|--------|------|
| 金银价格 | 今日涨跌、幅度 | 是否异动？ |
| TIPS 10Y | 绝对值、日变化 | 机会成本方向 |
| DXY | 绝对值、日变化 | 货币方向 |
| VIX | 绝对值、日变化 | 避险情绪 |
| 美债 10Y | 日变化 | 利率方向 |

**输出**：一句话概括当前状态。

> 示例："黄金 $4500，日内 +0.3%。TIPS 2.1% 日跌 2bp，DXY 99.2 平稳，VIX 17.4 中等。宏观环境偏多。"

**与上次判断对比**：

| 对比项 | 说明 |
|--------|------|
| 价格变化 | 当前价 vs macro_memo 上次价 |
| 因子变化 | 主导因子是否切换 |
| 事件变化 | 预期事件是否落地 |

变化不大 → 沿用上次判断，不做重复分析。
有重大变化 → 继续后续步骤。

### Step 2: 因子深度分析 `step_s2_factor_analysis`

**目标**：逐个因子读数，识别主导因子和边际变化。

**操作**：

```bash
# 获取完整因子数据
python data_query.py factors

# 或单因子详细数据
python data_query.py factors opportunity_cost
python data_query.py factors safe_haven
```

**每个因子的分析要点**：

| 因子 | 核心问题 | 重点关注 |
|------|---------|---------|
| 机会成本 | TIPS 趋势？降息预期？ | TIPS 20日趋势、FedWatch概率 |
| 货币 | DXY 趋势？正交贡献？ | DXY vs 200MA、独立于 TIPS 部分 |
| 避险 | VIX 水平？信用利差？ | VIX 趋势、是否流动性危机 |
| 通胀预期 | 盈亏平衡趋势？CPI momentum？ | Breakeven 趋势、原油 |
| 持仓动量 | OI 变化？COT 拥挤度？ | OI+价格组合信号、COT分位 |
| 结构性需求 | 央行购金趋势？ | 去美元化叙事 |
| 银价专用 | 金银比位置？工业需求？ | 金银比分位、库存趋势 |

**知识库查询规则**：

分析某个因子时，如遇到不理解或需要确认的指标，查对应 wiki：

| 指标/场景 | 查什么 |
|-----------|--------|
| TIPS 处于极端值 | `wiki_trade/wiki/指标手册/TIPS.md` |
| 金银比 > 90 | `wiki_trade/wiki/指标手册/金银比.md` |
| 因子间关系不确定 | `wiki_trade/wiki/宏观框架/*.md` |
| 特定指标解读 | `wiki_trade/entities/concepts/*.md` |

**输出**：每个因子的方向 + 强度 + 关键证据。

### Step 3: 技术面验证 `step_s3_technical_verify`

**目标**：价格行为是否支持因子信号？定位关键价位。

**操作**：

```bash
# 获取技术指标（主推方式，含 MA/RSI/MACD/ATR/ADX）
python data_query.py technical                    # 全部品种
python data_query.py technical shfe_gold          # 单品种
python data_query.py technical spot_silver

# 获取原始 K 线看趋势/形态（辅助）
python data_query.py history gold 30
python data_query.py history silver 30
```

**技术面检查清单**：

```
1. 趋势方向
   - MA20 在 MA60 之上/之下？（短期趋势）
   - MA60 在 MA200 之上/之下？（中期趋势）
   - 当前价在 MA 之上/之下？

2. 动量状态
   - 近期价格高低点排列（抬升/降低/横盘）
   - 是否有明显加速/减速特征

3. 超买超卖
   - 近期涨幅/跌幅是否异常（>2σ）
   - 是否连续多日同向运行

4. 关键价位
   - 近 30 日高/低点在哪
   - 是否有明显的整数位或前高前低

5. 背离检查
   - 价格与动量是否一致
   - 价格突破但持仓量不跟 → 信号弱
```

**双层信号对照表**：

| 因子信号 | 技术面信号 | 综合处理 |
|----------|-----------|---------|
| ↑ | 趋势向上，无超买 | 确认看多 ✅ |
| ↑ | 趋势向上，但超买/接近阻力 | 看多，等回调，不追高 |
| ↑ | 趋势向下或震荡 | 暂缓，因子与技术面冲突 |
| ↓ | 趋势向下，无超卖 | 确认看空 ✅ |
| ↓ | 趋势向下，但超卖/接近支撑 | 看空，等反弹，不杀跌 |
| ↓ | 趋势向上或震荡 | 暂缓 |
| 中性 | 趋势明确 | 轻仓顺技术面方向 |
| 中性 | 震荡 | 观望为主 |

### Step 4: 场景分类 `step_s4_scene_classify`

**目标**：判断当前价格波动主要由什么周期驱动——趋势、情绪还是噪音？

```bash
# 获取因子时间维度数据
python data_query.py factors
# 检查每个因子的 short/mid/long 信号
```

**判断流程**：

```
4a: 检查短期异常
  └─ 是否有因子短期信号强度 > 0.7？
       └─ 是 → 检查是否事件驱动（events/news）
            └─ 有事件触发 → 场景 = 情绪/事件驱动
            └─ 无事件触发 → 场景 = 可能是趋势加速/衰竭
       └─ 否 → 继续 4b

4b: 检查中期+长期方向
  └─ 中期和长期同向且强度一致（差异 < 0.2）？
       └─ 是 → 场景 = 趋势驱动
       └─ 否 → 继续 4c

4c: 检查是否矛盾信号
  └─ 短期与中长期方向相反？
       └─ 是 → 检查短期驱动因素
            └─ 短期是情绪性 → 场景 = 趋势中的回调
            └─ 短期是基本面 → 场景 = 可能转折
       └─ 否 → 继续 4d

4d: 检查信号一致性
  └─ 多空因子交织，无主导因子？
       └─ 是 → 场景 = 震荡/噪音
       └─ 否 → 场景 = 方向不明
```

**五种场景及处理策略**：

| 场景 | 特征 | 策略 | 适合操作 |
|------|------|------|---------|
| **1. 趋势驱动** | 中长期同向，短期无冲突 | 顺势，技术面找入场 | 持仓持有/加仓 |
| **2. 情绪/事件驱动** | 短期突变，中长期不变 | 等情绪消退，不做趋势判断 | 观望或小仓位短线 |
| **3. 震荡/噪音** | 信号混乱，无主导因子 | 观望，不做方向性判断 | 不操作或区间交易 |
| **4. 趋势中的回调** | 短期逆中长期方向，情绪性 | 回调企稳后加仓，不恐慌 | 持有，等企稳加仓 |
| **5. 可能转折** | 短期逆中长期方向，基本面驱动 | 减仓/对冲，等待确认 | 减仓保护利润 |

### Step 5: 信息增量 `step_s5_info_supplement`

**目标**：因子数据之外的补充信息。

**操作**：

```bash
# 本周重大事件
python data_query.py events

# 最新新闻（过滤与主导因子相关的）
python data_query.py news_by_factor <主导因子ID>

# 如知识库不足以解读当前场景
WebSearch 关键词
```

**何时需要 WebSearch**：

| 场景 | 搜什么 |
|------|--------|
| 突发地缘事件 | 事件进展、影响评估 |
| 央行意外决策 | 决策全文、市场评论 |
| 数据超预期 | 市场解读、分析师预期变化 |
| wiki 中没有的新概念 | 补充知识，后续写入 wiki |

**规则**：
- 优先用 `data_query` 获取结构化的数据
- 知识库能回答的，不搜网页
- WebSearch 结果需要交叉验证，不能全信

### Step 6: 场景推演 & 综合输出 `step_s6_scenario_projection`

**目标**：基于当前状态 + 本周事件，给出 2-3 条情景路径。

**推演方法**：

```
当前状态基准 → 主导因子 + 场景类型
     ↓
本周关键事件 → CPI / FOMC / 非农 / 地缘
     ↓
情景 A：事件符合预期 → 延续当前趋势 → 对持仓影响
情景 B：事件超预期(偏多) → 加速/反转 → 对持仓影响
情景 C：事件超预期(偏空) → 加速/反转 → 对持仓影响
```

**每条情景包含**：
- 发生的概率（高/中/低）
- 对金银价格的影响（方向 + 幅度）
- 对当前持仓的影响
- 什么情况下会切换到该情景

**输出规范**：

**箭头使用规则（全文档统一）**：
- `↑` / `↓` — 只表示**价格方向**（看多 / 看空）
- 因子变动描述中**禁用箭头**，用文字说明（例：加息预期升温 → 利空 ↓）
- `→` 中性 / `↑↓` 多空交织

**数据时效标注**：
输出顶部标注数据截至日期。如数据存在延迟差异，分点说明。

**引用标注规则**：
- 正文中引用外部报告/观点 → 用 `[N]` 上标标注（如 `[1]`、`[2]`）
- 输出末尾列出 `**参考文献**` 段落，按 `[N]` 序号列出来源
- 格式：`[N] 机构/作者, 标题/摘要, 来源链接（如有）`
- WebSearch 获取的信息也需标注 `(搜索)` 并附来源
- 知识库/工具直接读取的数据无需引用标注

**示例**：
```
下档支撑 $60（多家机构一致性目标）[1][2]
...
**参考文献**：
[1] 铜冠金源期货, 贵金属周报, 2026-06-08
[2] 广发期货, 金银策略月报, 2026-06-07
```

---

```
## 综合判断
看多 ↑ | 辅助置信度: 中 | 主导周期: 趋势驱动 | 主导因子: 机会成本
```

### macro_memo 更新格式 `step_memory_macro_memo`

```markdown
---
tags: [trading, memory, macro]
updated: 2026-06-08 10:30
---

# 宏观备忘录

## 当前判断
- **方向**: 看多 ↑
- **辅助置信度**: 中（信号一致度 0.65）
- **主导周期**: 趋势驱动
- **主导因子**: 机会成本（TIPS 下行）
- **上次变化**: 较上次上调（DXY 跌破 100）

## 关键点位
| 品种 | 支撑 | 阻力 | 趋势 |
|------|------|------|------|
| 黄金 | 4400 | 4600 | ↑ |
| 白银 | 72 | 78 | ↑ |
| DXY | 98 | 101 | ↓ |
| TIPS 10Y | 2.0 | 2.3 | ↓ |

## 因子信号摘要
```

## 四、特殊场景处理 `step_special`

### 4.1 数据缺失 `step_special_no_data`

| 情况 | 处理 |
|------|------|
| 某因子数据不全 | 在报告中标注"数据缺失"，降低该因子权重 |
| 全部数据缺失 | 告知用户数据管道异常，不做分析 |
| 行情与昨日无变化 | 沿用上次判断，不做重复分析 |

### 4.2 信号矛盾 `step_special_conflict`

| 矛盾类型 | 处理方式 |
|---------|---------|
| 因子间矛盾 | 找主导因子，弱势因子降低权重 |
| 因子与技术面矛盾 | 以因子方向为主，技术面提示时机风险 |
| 时间维度矛盾 | 按场景分类规则判断主导周期 |
| 自身判断与市场走势矛盾 | 优先市场走势，检讨判断错误原因 |

### 4.3 判断错误 `step_special_wrong`

当市场走势与分析判断明显相反时：

```
1. 诚实承认判断错误
2. 分析错在哪：
   a. 主导因子判断错误？
   b. 信号解读错误？
   c. 忽略关键变量？
   d. 不可预测的事件冲击？
3. 修正当前判断
4. 记录到 decisions.md
```

# 短线异动归因流程

> 用于急涨急跌时的快速归因。完整独立流程，不依赖标准分析流程。
>
> **触发条件**：用户告知"跌了/涨了"、日内波动 > 1%（黄金）或 > 2%（白银）、或用户主动要求归因。

**与标准分析流程的区别**：

| 维度 | 标准分析流程 | 短线异动归因 |
|------|------------|-------------|
| 节奏 | 逐步深度分析 | 极速归因，30秒内出初步结论 |
| 技术面 | 验证因子信号 | 跳过（异动本身就是技术事件） |
| 场景推演 | 必须做 | 不做，聚焦"当前发生了什么" |
| 知识库 | 需要时查 | 不查 |
| 输出 | 结构化报告 | 短平快，直接给原因+预期+建议 |

---

## 一、归因流程（六步）`step_anomaly`

```
Step 1: 确认异动参数（5秒）  `step_a01_confirm`
├─ 什么品种？跌/涨多少？从几点开始的？
├─ 当前还在动还是稳住了？
└─ 对比今日开盘价/昨日收盘

  ┌─ data_query.py snapshot → 当前价格 + 日跌幅
  └─ data_query.py history <品种> 5  → 近5根K线走势
       │
       ▼

Step 2: 事件排查 ← 第一优先级（10秒）  `step_a02_event_check`
├─ 有数据发布吗？（CPI / 非农 / PMI / 初请...）
├─ 有突发新闻吗？（地缘 / 央行 / 制裁 / 讲话...）
├─ 有美联储官员讲话吗？
└─ 事件实际值与预期值的差异（如有时效数据）

  ┌─ data_query.py events → 事件日历
  ├─ data_query.py news   → 突发新闻
  └─ WebSearch（如有必要）

    ──→ 先输出 Step 2 结论（告知是否有事件触发）
       │
       ├── 有明确事件 → 输出"事件初步归因"
       │    "CPI 超预期 0.3%，触发加息预期升温"
       │
       └── 无明确事件 → 告知"无事件触发，进入因子排查"

       ↓ （无论是否有事件，都继续 Step 3）

Step 3: 因子快速排查（15秒）  `step_a03_factor_check`
  按框架文档"短期异动归因逻辑"优先级排查：

  第一层：宏观因子排查
  ┌─ TIPS 急升/急降 → 机会成本驱动
  ├─ DXY 急涨/跌（且TIPS没动）→ 货币独立贡献
  ├─ VIX 跳升 → 避险驱动
  └─ TIPS/DXY/VIX 都没动 → 排除宏观因子

  第二层：品种间验证
  ├─ 金银同向 → 支持宏观归因
  ├─ 金跌银不跌 → 白银有工业属性对冲
  └─ 金银比急变 → 白银独立驱动

  第三层：持仓/OI异动
  └─ OI 骤降 → 平仓踩踏；OI 骤增 → 新开仓驱动

  第四层：技术性因素
  └─ 关键位突破触发止损连环单 / 交割日效应

  ┌─ data_query.py snapshot → TIPS/DXY/VIX 今日变化
  ├─ data_query.py macro   → 宏观指标详情
  └─ data_query.py factors → 因子数据综合
       │
       ▼

Step 4: 预期评估（10秒）  `step_a04_assessment`
  ├─ 触发因素是脉冲式的还是持续性的？
  │   ├─ 数据发布 / 讲话 → 脉冲式（市场几分钟内消化）
  │   ├─ 地缘事件 → 持续性（影响数天到数周）
  │   └─ 宏观因子转向 → 持续性（可能改变趋势）
  │
  ├─ 预计持续时间？
  │   ├─ 事件冲击 → 数分钟到数小时
  │   ├─ 宏观因子波动 → 数小时到数天
  │   └─ 趋势反转 → 数周到数月
  │
  └─ 可能的价格区间？
      ├─ 基于近 30 日 ATR 估算日内波动范围
      ├─ 当前价 ± 1×ATR → 正常波动区间
      ├─ 当前价 ± 2×ATR → 极端波动边界
      └─ 关键支撑/阻力位 → 可能止跌/止涨的位置

  ┌─ data_query.py history <品种> 30 → 计算 ATR + 关键位
       │
       ▼

Step 5: 持仓影响评估（5秒）  `step_a05_position_impact`
  ├─ 我有这个品种的持仓吗？方向多还是空？
  ├─ 当前价离成本 / 止损多远？
  └─ 需要立即行动吗？

  数据来源：positions.md（对话启动时已加载）
       │
       ▼

Step 6: 输出  `step_a06_output`
```

## 三、升级条件 `step_a07_upgrade_check`

异动归因完成后，判断是否需要升级为标准分析：

```
有事件触发 + 因子变动 > 1σ
   → 可能趋势转变 → 升级：执行标准分析流程 Step 4-6（场景分类+推演）
   → 更新 macro_memo（完整更新）

无事件 + 因子变动 < 1σ
   → 短期波动 → 不升级
   → 可选：记录到 macro_memo 异动记录中
```

## 四、极端行情 `step_a08_extreme`

触发条件：日内波动 > 2%（黄金）或 > 4%（白银）

处理流程：
1. 执行"短线异动归因流程" Step 1-5
2. 如有持仓，立即推送预警（飞书/对话）
3. 判断是否为流动性危机（VIX > 35 + 信用利差飙升 + DXY 走强）
4. 如是流动性危机 → 建议减仓，不抄底
5. 异动归因完成后，按升级条件判断是否需要补做标准分析
