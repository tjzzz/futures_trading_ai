# V1 Agent 分析标准操作流程 (SOP)

> Agent 执行宏观分析的标准步骤。每次分析按此流程执行。
> 
> **框架文档**：`1_金银价格驱动因子体系.md`（分析前读取）
> **依赖工具**：`data_query.py` / `compute_factors.py` / `analyze_macro.py`

---

## 一、分析前置

### 1.1 上下文加载

每次对话/分析开始，先加载：

```bash
# 1. 读取用户画像和持仓
#    (agent.md 记忆系统自动加载)
#    - user_profile.md  → 用户偏好、风险等级
#    - positions.md     → 当前持仓品种、方向、手数、成本

# 2. 读取上次宏观判断
#    - macro_memo.md    → 上次判断结论、关键点位、关注焦点

# 3. 读取框架文档
#    - 1_金银价格驱动因子体系.md → 确认分析框架
```

### 1.2 数据就绪检查

```bash
# 获取当前行情快照
python tools/data_query.py snapshot

# 获取因子数据
python tools/data_query.py factors

# 获取宏观指标
python tools/data_query.py macro
```

如果数据缺失或过期（>30min），告知用户数据延迟。

---

## 二、核心分析流程

```
Step 1: 宏观体检     → 快速扫描，了解当前状态
Step 2: 因子深度分析  → 七因子逐个读 + 查知识库
Step 3: 技术面验证    → 价格行为是否支持因子信号
Step 4: 场景分类      → 判断主导周期 + 市场regime
Step 5: 信息增量      → 事件/新闻/搜索补充
Step 6: 场景推演      → 2-3条情景路径 + 综合输出
```

---

### Step 1: 宏观体检（< 30秒）

**目标**：快速知道"当前是什么情况"，不深入分析。

**操作**：

```bash
python data_query.py snapshot
python data_query.py macro
```

**关注清单**：

| 指标 | 看什么 | 判断 |
|------|--------|------|
| 金银价格 | 今日涨跌、幅度 | 是否异动？ |
| TIPS 10Y | 绝对值、日变化 | 机会成本方向 |
| DXY | 绝对值、日变化 | 货币方向 |
| VIX | 绝对值、日变化 | 避险情绪 |
| 美债 10Y | 日变化 | 利率方向 |

**输出**：一句话概括当前状态。

> 示例："黄金 $4500，日内 +0.3%。TIPS 2.1% 日跌 2bp，DXY 99.2 平稳，VIX 17.4 中等。宏观环境偏多。"

**与上次判断对比**：

| 对比项 | 说明 |
|--------|------|
| 价格变化 | 当前价 vs macro_memo 上次价 |
| 因子变化 | 主导因子是否切换 |
| 事件变化 | 预期事件是否落地 |

变化不大 → 沿用上次判断，不做重复分析。
有重大变化 → 继续后续步骤。

---

### Step 2: 因子深度分析

**目标**：逐个因子读数，识别主导因子和边际变化。

**操作**：

```bash
# 获取完整因子数据
python data_query.py factors

# 或单因子详细数据
python data_query.py factors opportunity_cost
python data_query.py factors safe_haven
```

**每个因子的分析要点**：

| 因子 | 核心问题 | 重点关注 |
|------|---------|---------|
| 机会成本 | TIPS 趋势？降息预期？ | TIPS 20日趋势、FedWatch概率 |
| 货币 | DXY 趋势？正交贡献？ | DXY vs 200MA、独立于 TIPS 部分 |
| 避险 | VIX 水平？信用利差？ | VIX 趋势、是否流动性危机 |
| 通胀预期 | 盈亏平衡趋势？CPI momentum？ | Breakeven 趋势、原油 |
| 持仓动量 | OI 变化？COT 拥挤度？ | OI+价格组合信号、COT分位 |
| 结构性需求 | 央行购金趋势？ | 去美元化叙事 |
| 银价专用 | 金银比位置？工业需求？ | 金银比分位、库存趋势 |

**知识库查询规则**：

分析某个因子时，如遇到不理解或需要确认的指标，查对应 wiki：

| 指标/场景 | 查什么 |
|-----------|--------|
| TIPS 处于极端值 | `wiki_trade/wiki/指标手册/TIPS.md` |
| 金银比 > 90 | `wiki_trade/wiki/指标手册/金银比.md` |
| 因子间关系不确定 | `wiki_trade/wiki/宏观框架/*.md` |
| 特定指标解读 | `wiki_trade/entities/concepts/*.md` |

**输出**：每个因子的方向 + 强度 + 关键证据。

---

### Step 3: 技术面验证

**目标**：价格行为是否支持因子信号？定位关键价位。

**操作**：

```bash
# 获取历史行情看趋势/形态
python data_query.py history gold 30
python data_query.py history silver 30
```

**技术面检查清单**：

```
1. 趋势方向
   - MA20 在 MA60 之上/之下？（短期趋势）
   - MA60 在 MA200 之上/之下？（中期趋势）
   - 当前价在 MA 之上/之下？

2. 动量状态
   - 近期价格高低点排列（抬升/降低/横盘）
   - 是否有明显加速/减速特征

3. 超买超卖
   - 近期涨幅/跌幅是否异常（>2σ）
   - 是否连续多日同向运行

4. 关键价位
   - 近 30 日高/低点在哪
   - 是否有明显的整数位或前高前低

5. 背离检查
   - 价格与动量是否一致
   - 价格突破但持仓量不跟 → 信号弱
```

**双层信号对照表**：

| 因子信号 | 技术面信号 | 综合处理 |
|----------|-----------|---------|
| ↑ | 趋势向上，无超买 | 确认看多 ✅ |
| ↑ | 趋势向上，但超买/接近阻力 | 看多，等回调，不追高 |
| ↑ | 趋势向下或震荡 | 暂缓，因子与技术面冲突 |
| ↓ | 趋势向下，无超卖 | 确认看空 ✅ |
| ↓ | 趋势向下，但超卖/接近支撑 | 看空，等反弹，不杀跌 |
| ↓ | 趋势向上或震荡 | 暂缓 |
| 中性 | 趋势明确 | 轻仓顺技术面方向 |
| 中性 | 震荡 | 观望为主 |

### Step 4: 场景分类 ⭐（核心智能）

**目标**：判断当前价格波动主要由什么周期驱动——趋势、情绪还是噪音？

#### 分类规则

```bash
# 获取因子时间维度数据
python data_query.py factors
# 检查每个因子的 short/mid/long 信号
```

**判断流程**：

```
Step 4a: 检查短期异常
  └─ 是否有因子短期信号强度 > 0.7？
       └─ 是 → 检查是否事件驱动（events/news）
            └─ 有事件触发 → 场景 = 情绪/事件驱动
            └─ 无事件触发 → 场景 = 可能是趋势加速/衰竭
       └─ 否 → 继续 Step 4b

Step 4b: 检查中期+长期方向
  └─ 中期和长期同向且强度一致（差异 < 0.2）？
       └─ 是 → 场景 = 趋势驱动
       └─ 否 → 继续 Step 4c

Step 4c: 检查是否矛盾信号
  └─ 短期与中长期方向相反？
       └─ 是 → 检查短期驱动因素
            └─ 短期是情绪性 → 场景 = 趋势中的回调
            └─ 短期是基本面 → 场景 = 可能转折
       └─ 否 → 继续 Step 4d

Step 4d: 检查信号一致性
  └─ 多空因子交织，无主导因子？
       └─ 是 → 场景 = 震荡/噪音
       └─ 否 → 场景 = 方向不明
```

#### 五种场景及处理策略

| 场景 | 特征 | 策略 | 适合操作 |
|------|------|------|---------|
| **1. 趋势驱动** | 中长期同向，短期无冲突 | 顺势，技术面找入场 | 持仓持有/加仓 |
| **2. 情绪/事件驱动** | 短期突变，中长期不变 | 等情绪消退，不做趋势判断 | 观望或小仓位短线 |
| **3. 震荡/噪音** | 信号混乱，无主导因子 | 观望，不做方向性判断 | 不操作或区间交易 |
| **4. 趋势中的回调** | 短期逆中长期方向，情绪性 | 回调企稳后加仓，不恐慌 | 持有，等企稳加仓 |
| **5. 可能转折** | 短期逆中长期方向，基本面驱动 | 减仓/对冲，等待确认 | 减仓保护利润 |

**特殊场景——流动性危机**：
```
条件: VIX > 35 + 信用利差飙升 + DXY 走强
处理: 立即触发预警，建议减仓
      不抄底，等流动性恢复后重新评估
```

---

### Step 5: 信息增量

**目标**：因子数据之外的补充信息。

**操作**：

```bash
# 本周重大事件
python data_query.py events

# 最新新闻（过滤与主导因子相关的）
python data_query.py news_by_factor <主导因子ID>

# 如知识库不足以解读当前场景
WebSearch 关键词
```

**何时需要 WebSearch**：

| 场景 | 搜什么 |
|------|--------|
| 突发地缘事件 | 事件进展、影响评估 |
| 央行意外决策 | 决策全文、市场评论 |
| 数据超预期 | 市场解读、分析师预期变化 |
| wiki 中没有的新概念 | 补充知识，后续写入 wiki |

**规则**：
- 优先用 `data_query` 获取结构化的数据
- 知识库能回答的，不搜网页
- WebSearch 结果需要交叉验证，不能全信

### Step 6: 场景推演 & 综合输出

**目标**：基于当前状态 + 本周事件，给出 2-3 条情景路径。

#### 推演方法

```
当前状态基准 → 主导因子 + 场景类型
     ↓
本周关键事件 → CPI / FOMC / 非农 / 地缘
     ↓
情景 A：事件符合预期 → 延续当前趋势 → 对持仓影响
情景 B：事件超预期(偏多) → 加速/反转 → 对持仓影响
情景 C：事件超预期(偏空) → 加速/反转 → 对持仓影响
```

**每条情景包含**：
- 发生的概率（高/中/低）
- 对金银价格的影响（方向 + 幅度）
- 对当前持仓的影响
- 什么情况下会切换到该情景

#### 综合输出格式

```
📊 宏观分析 | YYYY-MM-DD HH:mm

## 综合判断
看多 ↑ | 辅助置信度: 中 | 主导周期: 趋势驱动 | 主导因子: 机会成本

## 各因子信号
| 因子 | 信号 | 强度 | 要点 |
|------|------|------|------|
| 机会成本 | ↑ | 0.8 | TIPS 下行至 2.1% |
| 货币 | — | 0.0 | DXY 平稳 |
| 避险 | ↑ | 0.3 | VIX 17.4 中等 |
| 通胀预期 | — | 0.0 | 盈亏平衡平稳 |
| 持仓动量 | ↑ | 0.2 | OI 增加 |
| 结构性需求 | ↑ | 0.4 | 央行购金持续 |
| 银价专用 | — | 0.0 | 金银比 85 |

## 技术面
黄金: 趋势 ↑ | 动量 中性 | 关键位 支撑 4400 / 阻力 4600
白银: 趋势 ↑ | 动量 偏强 | 关键位 支撑 72 / 阻力 78

## 情景推演
| 情景 | 概率 | 触发 | 影响 |
|------|------|------|------|
| 基准 | 高 | 无新增变量 | 黄金维持 4400-4600 震荡偏多 |
| 偏多 | 中 | CPI低于预期 | 黄金突破 4600，上看 4750 |
| 偏空 | 低 | FOMC意外鹰派 | 黄金回调至 4300 |

## 对持仓影响
- COMEX 黄金多单: 持有，止损上移至 4380
- 沪银: 持有观望

## 风险提示
⚠️ COT 净多头接近 85% 分位，若趋势反转回调幅度可能较大
⚠️ 周四 CPI 是关键变量，数据前控制仓位
```

## 四、特殊场景处理

### 4.1 数据缺失

| 情况 | 处理 |
|------|------|
| 某因子数据不全 | 在报告中标注"数据缺失"，降低该因子权重 |
| 全部数据缺失 | 告知用户数据管道异常，不做分析 |
| 行情与昨日无变化 | 沿用上次判断，不做重复分析 |

### 4.2 信号矛盾

| 矛盾类型 | 处理方式 |
|---------|---------|
| 因子间矛盾 | 找主导因子，弱势因子降低权重 |
| 因子与技术面矛盾 | 以因子方向为主，技术面提示时机风险 |
| 时间维度矛盾 | 按场景分类规则判断主导周期 |
| 自身判断与市场走势矛盾 | 优先市场走势，检讨判断错误原因 |

### 4.3 极端行情

触发条件：日内波动 > 2%（黄金）或 > 4%（白银）

```
处理流程：
1. 立即获取 snapshot + events + news
2. 执行"短期异动归因逻辑"（按框架文档优先级）
3. 判断是否有持续影响还是短期冲击
4. 更新 macro_memo（标注"异动"）
5. 如涉及持仓，推送预警
```

### 4.4 判断错误

当市场走势与分析判断明显相反时：

```
1. 诚实承认判断错误
2. 分析错在哪：
   a. 主导因子判断错误？
   b. 信号解读错误？
   c. 忽略关键变量？
   d. 不可预测的事件冲击？
3. 修正当前判断
4. 记录到 decisions.md
```
